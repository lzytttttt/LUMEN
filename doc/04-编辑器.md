# 04 编辑器 —— 画布交互、命令与快捷键

> 本文覆盖 `src/editor/**` 与画布相关的 `src/state/*`：画布结构、缩放平移、命中测试、拖拽/缩放/旋转、吸附、撤销合并、内联改字、快捷键、拖放与粘贴。
> 渲染契约见 `doc/05-SVG与3D渲染.md`；块字段见 `doc/03-数据模型与DSL.md`。

## 1. 画布结构

DOM 是五层，自上而下：

| 层 | 节点 | 职责 | pointer-events |
|---|---|---|---|
| 外壳 | `.app-stage` | HUD、对齐条、右键菜单、拖放提示 | auto |
| 视口 | `.stage-viewport` | `useElementSize()` 量尺寸、居中、裁剪（`padding: 28px`） | auto |
| 平面 | `.stage-plane` | 尺寸 = `STAGE_W/H × scale`，`translate3d(pan)` 做平移 | auto |
| 舞台 | `.stage-frame` | `transform: scale(scale)` + `--d-*` 主题变量 + `--px` | auto |
| 内容 | `.lumen-slide`（`SlideRenderer`） | 永远是 1600×900 设计像素 | stage 模式下 `none` |
| 交互 | `.stage-surface`（z 5） | 唯一命中层 | auto |
| 覆盖 | `.stage-overlay`（z 10） | 选择框、8 手柄、旋转柄、参考线、框选、角标 | 除手柄外 `none` |

- 缩放**只做一次**（`.stage-frame`）；`.stage-plane` 只负责占位与平移位移。
- 覆盖层所有尺寸写成 `calc(N * var(--px))`，`--px = 1 / max(scale, 0.01)`，所以 30% 与 100% 缩放下手柄/参考线/角标的**屏幕粗细一致**。
- 网格与安全区（`.stage-grid` / `.stage-safe`）只在 `showGrid` 为真时渲染；网格线 40px 一级、160px 加重，安全区虚线固定在 `120/96` 内缩。

## 2. 缩放与平移

| 行为 | 实现 | 参数 |
|---|---|---|
| 适配 | `min(viewportW / 1600, viewportH / 900)`，量不到时用 `0.5` | `zoom === 'fit'` |
| HUD −/+ | 每次 ±0.1，保留两位小数 | `MIN_ZOOM 0.1` – `MAX_ZOOM 3` |
| 滚轮缩放 | 仅 `Ctrl/Cmd + wheel`：`factor = exp(−deltaY × 0.0016)`，三位小数取整，`passive: false` | 锚点 = 指针下的设计像素坐标 |
| 锚点校正 | `useLayoutEffect([scale])`：缩放后量真实 `rect`，把锚点差值补进 `pan` | 阈值 0.5px 内不动 |
| 平移 | 空格按住 或 鼠标中键拖动 | `pan` 是 `Stage` 的局部 `useState`，**不进 store** |
| 空格态 | `keydown/keyup` 监听；`isTypingTarget()` 时忽略；`blur` 复位 | 光标 `grab`/`grabbing` |

`zoom` 存在 `uiStore`（`'fit' | number`），`pan` 只活在外壳里——切幕不会重置缩放，刷新会。

## 3. 命中测试与选择

命中在**纯几何层**（`stage/geometry.ts`）算，渲染内容不吃事件：

```ts
hitTestBoxes(slide.blocks, point, { includeLocked: event.altKey })
// 内部：按 z 升序排序后从高到低找；hidden 跳过；locked 只有在 includeLocked 时才认
```

| 规则 | 行为 |
|---|---|
| 旋转 | `pointInBox()` 先把点逆旋转进块本地坐标再判定，所以旋转块的命中是真实形状 |
| 选择框 | 单选：块自身矩形 + CSS `rotate`；多选：`unionBounds(旋转后外接框)` 的并集 |
| 框选 | `marqueeBoxes()` 用**旋转后外接框**做相交测试（`rectsIntersect`），不追求精确包含 |
| Shift | 命中已选中块 → 从选中集移除；未选中 → 追加；空白处 Shift 拖动 = 追加式框选 |
| Alt | 允许命中选择**锁定块**（右下角仍可改属性），但锁定块不进入拖动列表 |
| 悬停 | `onSurfacePointerMove` 只在高亮目标变化时写 `selectionStore.setHovered()` |
| 双击 | 命中 `text` 块 → `startEditingBlock(id, { point })`；双击空白 → 退出编辑 + 清选择 |
| 右键 | 命中包含锁定块；未选中则先选中，再打开 `BlockContextMenu` |

## 4. 拖拽 / 八向缩放 / 旋转

### 4.1 指针管线

- 按下即判断分支：中键或空格 → `pan`；工具不是 `select` → `draw`；命中 → `move`；空白 → `marquee`。
- 移动只把最新事件写进 `pendingRef`，用 **rAF 合帧**，一帧最多一次写库；`pointerup` 先 `flush()` 再收尾。
- 拖拽期 `pointermove/pointerup/pointercancel` 走 **window 级监听**：手柄 `setPointerCapture` 后事件目标变成手柄自身，不会冒泡回 `.stage-surface`。
- `Esc`（capture 阶段）与 `pointercancel` 都走 `cancelDrag()`：把几何/角度还原成拖动前，再 `finishDrag(false)`。
- 点击判定有 3px 屏幕像素容差（`CLICK_SLOP_PX = 3`，乘 `scale` 换算）。

### 4.2 移动吸附

```ts
const snapped = snapMove(moved, drag.lines, { threshold: 6, grid: GRID }) // GRID = 8
```

1. 候选线 = 舞台（`0 / 120 / 800 / 1480 / 1600`，y 同理用 `96/450/804`）+ 同级块的左/中/右、上/中/下。
2. 三条边（起/中/止）各自与候选线比，取阈值内**最近**的一对 → 6px 智能参考线。
3. 两轴都没命中 → 降级为 `roundTo(8)` 网格吸附。
4. 位移再经 `clampMoveDelta()` 约束：整组至少留 24px 在舞台内（约束的是位移量，多选相对位置不漂），落库前每块再过一次 `clampToStage()`。
5. 旋转块参与吸附时用其外接框边线（避免吸到看不见的轴）。

### 4.3 八向缩放与旋转

- 8 个手柄 `HANDLES`（`nw n e ne se s sw w`），`fx/fy ∈ {0, 0.5, 1}` 表达"哪条边在动"。
- `resizeRect()` 把位移逆旋转进块本地坐标 → 算新 `w/h` → 以对边/对角（`Alt` 时以中心）为锚点反算中心。`Shift` 在角手柄上做等比（取变化更大的轴）。
- 最小尺寸 `MIN_SIZE = 8`；缩放后的边吸附（`snapResizeEdge`）**仅在块未旋转且未按 Alt 时**启用。
- 多选缩放：`scaleBoxes()` 把整组矩形按并集框的比例映射，不做逐块 clamp 之外的修正。
- 旋转手柄只出现在**单选**时：`angleDeg(center, point)` 差值加到起始角度，`Shift` 吸到 15°，否则 0.5°，最后 `normalizeAngle()` 归一到 (-180, 180]。
- 角标（`.stage-badge`）实时显示 `W × H` 或角度。

## 5. 撤销合并

| 操作 | 写入 | coalesceKey |
|---|---|---|
| 移动 / 缩放 | `blockOps.setGeometry()` | `'drag'` |
| 旋转 | `blockOps.update(..., 'rotate-block')` | `'rotate'` |
| 方向键微调 | `blockOps.nudge()` | `'nudge'` |
| 属性面板数值 | `blockOps.updateOptions()` | `opts-<blockId>` |
| 多块插入 / 复制 / AI 落稿 | `transaction(label, fn)` | 走分组，不靠 coalesce |

- 合并条件：**同一个 coalesceKey** 且距上一笔 < `COALESCE_MS = 650`；命中就把新补丁并进上一笔，逆补丁倒序拼接。
- 一次连续拖拽 = 一步撤销；间隔超过 650ms 的两次拖动 = 两步。
- 分组（`transaction`）期间所有 `update` 都进 `group`，`endGroup()` 时空组直接丢弃。
- 栈上限 `HISTORY_LIMIT = 200`；`future` 在任意新补丁到来时清空。

## 6. 内联改字

`InlineTextEditor` 是覆盖在块上的 `contentEditable="plaintext-only"`，样式与渲染层同源（同一套 `--d-*` 变量 + 块的 `lineHeight/tracking/weight/align/color`）。

| 输入 | 行为 |
|---|---|
| `blur` | 提交（`commitTextEdit`），一次历史 |
| `Esc` | 取消，不写库 |
| `Enter` | 插入 `\n`（不提交） |
| `⌘/Ctrl + Enter` | 提交 |
| IME 合成中 | 不提交、不拦 `Enter`（同时看 `nativeEvent.isComposing` 与本地 `composingRef`） |
| 粘贴 | 只取 `text/plain`，`preventDefault()` 后手工插入到光标 |
| 其它按键 | 全部 `stopPropagation()`，避免方向键/删除被全局快捷键抢走 |

提交时的清洗：`\r\n → \n`、去掉行尾空白、截断 6000 字符；内容没变则不产生历史；空文本也保留块（只清内容）。
进入编辑时的光标意图（是否全选、双击落点）走 `interactions/editingIntent.ts` 的一次性通道，读完即清空。渲染层同时把该块的 `.lumen-text` 设为 `visibility: hidden`，避免双份描边。

## 7. 快捷键总表

唯一的表在 `src/editor/shortcuts.ts` 的 `SHORTCUTS`（安装一次，返回卸载函数），`⌘K` 与 `Shift+S` 在 `App.tsx` 里单独处理。

| id | keys | 行为 |
|---|---|---|
| `undo` | `⌘/Ctrl + Z` | `historyOps.undo()` |
| `redo` | `⌘/Ctrl + Shift + Z`（也接 `⌘/Ctrl + Y`） | `historyOps.redo()` |
| `copy` | `⌘/Ctrl + C` | 写内部 JSON 剪贴板 |
| `cut` | `⌘/Ctrl + X` | 写剪贴板 + 删除 |
| `paste` | `⌘/Ctrl + V` | 内部剪贴板为空时返回 `false`，放行给系统粘贴事件 |
| `duplicate` | `⌘/Ctrl + D` | 复制选中块（偏移 24px，新 id，事务一步） |
| `selectAll` | `⌘/Ctrl + A` | 选中当前幕所有未锁定、未隐藏的块 |
| `play` | `⌘/Ctrl + Enter` | `mode` 在 `play`/`edit` 之间切换 |
| `delete` | `Delete` / `Backspace` | 删除可写选中块 |
| `nudge` | `↑ ↓ ← →` | 位移 1px；按住 `Shift` 为 10px |
| `grid` | `G` | 显示/隐藏网格与安全区 |
| `toolSelect` | `V` | 选择工具 |
| `toolText` | `T` | 文本工具（画布上点击/拖出文本框） |
| `toolRect` | `R` | 矩形工具 |
| `escape` | `Esc` | 逐级退出：编辑中 → 清选择 → 工具回选择 → 退出播放/预览 |
| — | `⌘/Ctrl + K` | 命令面板开关（`App.tsx`） |
| — | `Shift + S` | 在末尾新增一幕（`App.tsx`） |

全局门控（`installShortcuts`）：

- `event.defaultPrevented` 或 `event.isComposing` → 全部让位；
- 焦点在 `INPUT/TEXTAREA/SELECT` 或 `contentEditable` → 全部让位（`isTypingTarget`）；
- 非 `edit` 模式只保留 `escape` 与 `play`（把方向键留给播放器翻页）；
- `run()` 返回 `false` 表示"不消费"，浏览器保留默认行为（粘贴即走这条）。

## 8. 拖放与粘贴

拖放与系统粘贴共用 `editor/dnd/blocksFromData.ts`，只产出"块 + 提示"，落点由调用方决定。

| 来源 | 判定 | 产出 | 尺寸策略 |
|---|---|---|---|
| 图片文件 | `type.startsWith('image/')` | `image` 块（`importImageFile` 落库为 WebP 资产） | `fitSize(w, h, 720, 720)`，`alt = 文件名` |
| `.svg` / `image/svg+xml` | 读文本 → `sanitizeSvgDocument()` | `svg` 块 | 按 `viewBox` 保比例，最大边 720 |
| `.html/.htm` / `text/html` | 读文本 | `html` 块 | 固定 `720 × 420`，截断 `200*1024` 字符 |
| `.txt/.md` / `text/plain` | 含 `<svg` → svg 块；含标签 → html 块；否则纯文本块 | `text` 块兜底 | `640 × min(400, 48 + ceil(len/48) × 40)` |
| 其它 | — | 无 | 弹 toast `editor.stage.unsupportedFile` |

- 拖放落点：`stagePointFromClient()` 换算成设计像素 → `insertBlocksAt()` 以该点为**视觉中心**、多块按 24px 阶梯错位，再 `fitIntoSafe()` 收进安全区（放不下则居中）。
- 拖放视觉：`.stage-drop` 虚线遮罩 + `editor.stage.dropHere`；用 `dragDepthRef` 计数避免子元素 `dragleave` 抖动。
- 系统粘贴（`installShortcuts` 的 `paste` 监听）：必须**同步** `preventDefault()`（异步解码图片前浏览器已不会再插入文本），再 `blocksFromClipboardData()`；图片优先，其次 `text/plain`，再 `text/html`。
- 内部剪贴板（`interactions/clipboard.ts`）：深拷贝块，每次粘贴偏移 `24 × 粘贴次数` 并换新 id，几何 `clampToStage()`。

## 9. 右键菜单与对齐条

- `BlockContextMenu`：置顶/上移/下移/置底、复制、锁定/解锁、隐藏、删除；多选时插入 6 个对齐模式 + 两个分布轴。菜单 `position: fixed`，贴边时自动内收 8px。
- `StageAlignBar`：`count < 2` 不渲染，`count >= 3` 才出现分布按钮；对齐的参考物是**块数组顺序里第一个**选中块（`ops.align()` 里 `reference = selected[0]`），不是最后点击的那个。
- 工具落块：文本工具默认 `640 × 148`、矩形工具 `360 × 220`；拖出的矩形大于 10px 屏幕尺寸时按实际尺寸落块，否则用默认尺寸。

## 10. 插入元素与命令入口

插入菜单、命令面板、快捷键之外的"加一个块"都走 `toolbar/insertActions.ts`；落点统一由 `panels/insertGeometry.ts` 的 `centeredRect()` 算：**先夹进安全区（1360×708），再在舞台居中**（注意与画布工具不同：`T`/`R` 工具落块用 `centerBoxAt(point)`，落在光标处）。

| 元素 | 默认尺寸（设计像素） | 备注 |
|---|---|---|
| 文本 `display` | 960 × 240 | 每个字阶都有示例文案（中/英各一套） |
| 文本 `h1` / `h2` | 900 × 200 / 760 × 140 | |
| 文本 `lead` / `body` | 760 × 130 / 720 × 180 | |
| 文本 `caption` / `mono` | 520 × 60 / 640 × 100 | |
| 形状 `rect/ellipse/triangle` | 480 × 320 | `rect` 带 `radius: 12`，`fill: surface` |
| 形状 `line/rule` | 520 × 8 | `fill: accent` |
| 图片 | 720 × (720 × 高宽比) | `INSERT_IMAGE_W = 720`，高度封顶安全区 |
| SVG（空白） | 800 × 450 | `blankSvgSource()` |
| SVG（精选库/粘贴源码） | 760 × (760 × vbH/vbW) | 先净化，失败则 toast 并返回 `null` |
| 3D | 760 × 520 | `descriptor: parse({ preset })` |
| HTML | 760 × 460 | `blankHtmlSource()` |

命令面板（`⌘K`）的命令表在 `toolbar/commandRegistry.ts`：分类固定为 `deck / slide / block / view / ai / export`，检索同时匹配本地化标题与命令 id，副作用由调用方注入的 `CommandContext` 承担（因此可以拿假 ctx 在单测里整表跑一遍）。

## 11. 已知限制

- 拖动**每帧都写 deck**：历史合并只减少撤销步数，不能减少 React 重渲染与 autosave 抖动（切幕/大幕时有可见成本）。
- 多选不支持旋转（旋转柄只在单选时出现）；多选缩放时块自身 `rotation` 保持不变，但用未旋转的并集框做映射，旋转块的观感会与手柄位置有偏差。
- 平移（`pan`）与拖拽中间态不进 store，切幕/刷新后回到居中；`zoom` 反而在 `uiStore` 里，两者生命周期不一致。
- 缩放吸附对旋转块关闭（`|rotation| < 0.01` 才启用），这是精度换确定性的取舍。
- 参考线只来自**当前幕**的块与舞台边界，不跨幕、不对齐到网格线本身。
- 内联改字只支持 `text` 块；SVG/HTML/3D 的内容编辑要走工作室或弹窗。
- 撤销入口已收敛（**已修复**）：`TopBar.tsx` 曾经自己再注册一份 `⌘/Ctrl+Z` / `⌘/Ctrl+Shift+Z` 的 window 监听，与 `SHORTCUTS` 的 `undo/redo` 重复（`stopPropagation()` 拦不住同一节点上的其它监听器，一次按键可能撤销两步）。现在这份监听已移除，键盘撤销/重做**只由 `editor/shortcuts.ts` 处理**，顶栏按钮只调 `useDeckStore` 的 `undo/redo`。
- 撤销是 deck 级的：它不会恢复选中集、`editingBlockId` 或 `activeSlideId`，删幕撤销后可能停在别的幕上。
- 命令面板显示的快捷键提示与实际绑定不一致：`slide.new` 标的是 `⌘⇧N`（真实绑定是 `Shift+S`），`slide.duplicate` 标的是 `⌘D`（真实 `⌘D` 复制的是**块**）。改文案要连同 `commandRegistry.ts` 一起收敛。
- 插入动作有两条落点规则（菜单/命令用舞台居中 `centeredRect`，画布工具用光标处 `centerBoxAt`），同一元素从不同入口进来位置不同。
