# 01 产品概述 —— LUMEN · 幕光

> 一份演示，不该是一个文件；它该是一件能跑起来的作品。

## 1. 一句话

**LUMEN 是一个浏览器里的 AI 原生演示工作台**：用一句话生成大纲，逐幕成稿，可视化编辑，全屏播放，最后一键导出成**双击就能播的单文件 HTML**。SVG 与 three.js 不是"插入的素材"，而是演示的一等公民。

## 2. 为什么是 HTML，而不是又一个 PPT

| | 传统 PPT | LUMEN |
|---|---|---|
| 交付物 | 二进制文件 | 单文件 HTML（无依赖、可播、可索引） |
| 版式 | 手工对位置 | 主题令牌 + 12 列栅格 + 版式配方，AI 与人都只能在"好设计空间"里工作 |
| 内容 | 静态文本与图片 | 结构化的幕/块，可检索、可 diff、可迁移 |
| 交互 | 翻页 | 翻页 + 可交互 HTML 块 + 可拖动的 3D 场景 |
| 迭代 | 重新排版 | 改一处，全篇更新；导出版与原稿同一套渲染器 |
| 生成 | 无 | 大纲 → 逐幕 → 局部重写 → 自然语言微调 |

## 3. 七条 AI 原生原则（产品即证据）

| # | 原则 | 在界面里长什么样 |
|---|---|---|
| P1 | **提示优先，画布其次** | 右栏 AI 编排与 ⌘K 命令面板是主入口；画布用于校正，不用于从零搭建 |
| P2 | **输出是结构，不是截图** | AI 只产出大纲、槽位、场景描述符；每一块都能继续被拖动、改写、换主题 |
| P3 | **约束即品味** | 12 个版式配方 × 6 套主题 × 一套字号阶；AI 不能自由发挥 CSS |
| P4 | **可追溯、可回滚** | 每个 AI 块带 provenance 徽标，可查看提示、可还原 AI 版本 |
| P5 | **本地优先** | IndexedDB 持久化、无后端、无遥测；模型端点由用户自填（含本地 Ollama），默认离线 Mock |
| P6 | **同一渲染器** | 编辑、缩略图、播放、打印、PNG、独立 HTML 播放器共用一个 `SlideRenderer` |
| P7 | **质量即 lint** | 溢出、对比度、字号下限、3D 预算、阅读时长统一检查，AI 产物与人工产物同一把尺子 |

## 4. 四条主线

```
生成            编辑                  播放                 导出
提示→大纲→逐幕   选择/拖拽/吸附         全屏/转场/讲者视图     独立 HTML
SVG/3D 生成     属性/图层/动效/主题     键盘/翻页器/自动播放   PDF / PNG / 工程文件
```

### 4.1 生成
- **整套**：主题 + 听众 + 时长 + 语言 → 大纲（可编辑、可拖排）→ 逐幕成稿。
- **单点**：重写当前幕、精简文案、把要点改成时间轴、加一张矢量插图、加一个 3D 场景。
- **风格**：只在大纲与配方层表达；不产生不可维护的样式代码。

### 4.2 编辑
- 舞台 1600×900 设计像素，等比缩放；块级绝对定位。
- 选择（含框选/多选）、八向缩放、旋转、吸附（智能参考线 + 网格）、对齐分布、层级、锁定隐藏。
- 内联改字、检查器精确数值、撤销重做（补丁栈，200 步）、剪贴板。
- 六种块：`text` / `shape` / `image` / `svg` / `three` / `html`（沙箱 iframe）。

### 4.3 播放
- 全屏播放、五种转场、键盘与翻页器、讲者视图（备注 + 计时 + 下一幕）、总览、自动播放。
- 3D 只在当前幕运行，离屏即停；缩略图不创建 WebGL 上下文。

### 4.4 导出
- **独立 HTML**：单文件，内联播放器内核与素材，`file://` 双击即播；也支持 `?print=1` 打印成 PDF。
- **PDF**：应用内打印路由，逐幕渲染，3D 幕先抓帧。
- **PNG**：逐幕 2× 位图。
- **工程文件**：`.lumen.json`（含素材），可与他人交换或在别的机器上继续编辑。

## 5. SVG 与 three.js 的产品地位

- **SVG**：矢量、可主题换色、体积小，是"插图"的默认形态。AI 生成的 SVG 会经过白名单净化与颜色令牌化，保证任意主题下都成立。播放时支持描边生长、漂浮、呼吸、缓慢旋转。
- **three.js**：不是装饰，是"记忆点"。用受限的场景描述符（预设 + 形体 + 材质 + 灯光 + 运动）换取三件事：确定性、性能、可导出。每个演示建议不超过 2 个 3D 幕。

## 6. 双语与可访问性

- UI 全量中/英，语言可即时切换；演示内容语言独立（示例 deck 自带双语版本）。
- 仅系统字体栈，避免跨机字体漂移；对比度参与 lint；`prefers-reduced-motion` 关闭动效；键盘可达、焦点可见。

## 7. 非目标（v1）

PPTX 导入/导出、多人实时协作、服务端渲染农场、视频导出、移动端编辑（仅只读播放）。

## 8. 成功的样子

打开页面 3 秒内看到一套 9 幕示例；按 ⌘K 输入一句话能得到可编辑的大纲；拖一次、改一行字、撤销三次再重做；进全屏讲完 9 幕；导出一个 4MB 以内的 HTML 文件，发到别人电脑上双击，仍然能播。
