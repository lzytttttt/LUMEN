## 1. 语气规范

总纲：**像同事递给你一张纸，不像产品向你推销。**

| # | 规则 | 反例 → 正例 |
|---|---|---|
| 1 | 动词优先：按钮是动作，不是应答 | 确定 / 取消 → 开始生成 / 收起 |
| 2 | 数字即文案：能数就不用说 | 正在生成中 → `3/9` |
| 3 | 不抒情：零人称，没有「为谁」也没有「努力」「期待」 | 正在为你努力生成 → `4/9` |
| 4 | 零感叹号、零省略号（`！` `!` `…` 全禁） | 生成完成！ → 通过 |
| 5 | 术语统一按 `00` §5：**界面只用「界面词」**（输入 / 大纲 / 生成 / 检查 / 播放 / 生成大纲 / 开始生成 / 重试），代号（起念 / 抽幕 / 铸造 / 过检 / 重铸 / 开演）只出现在 i18n key 与代码里 | 幻灯片 / PPT / 一键生成 → 幕 / 一套 / 生成大纲 |

> **本文是界面字符串的唯一真相**（`00` D13）。凡是本文写成「输入 / 大纲 / 生成 / 检查 / 播放」的地方，代码里的 key 仍叫 `seed / deal / cast·assemble / gate / premiere`——**key 不改、只改文案**，这是本次同步的唯一动作。

一句话原则：**屏幕上的每个字都要能被数、被点、被比较**；数不出、点不到、比不了的字，删掉。

## 2. 完整文案表

本文共定义 **111 条 `forge.*` 文案位**，另复用 **9 条**既有键（6 条 `ai.panel.preset.*` + 3 条旧键，见 §3.3）。

### 2.0 字数上限的六个类别

| 类 | 用途 | 中文上限 | 英文上限 | 出处 |
|---|---|---|---|---|
| **A** | 阶段词（流程脉冲） | 4 字 | 7 符 | 00 D5 + 本文补充 |
| **B** | 动作按钮 / 状态词 / 档位名 | 3 字 | 8 符 | 00 §5「动作名天然 ≤8 字符」 |
| **C** | 标签 / 错误气泡 | 6 字 | `⌈2.9n⌉` 符（3→9、4→12、5→15、6→18） | 00 §7.7 的 1.6× 换算 |
| **D** | 用户内容预览（示例句、占位符） | ≤14 字 | ≤28 符 | D5 的"唯一长句"例外 |
| **E** | 品牌名 / 产品名 | ≤8 字 | ≤10 符 | DeepSeek、OpenAI、Ollama |
| **F** | 计数器（数字 + ≤1 个单位词或符号） | 不设字数，只设 1 个单位词 | 同左 | D5「数字即文案」 |

「字」= 汉字个数（标点与占位符不计）；「符」= 英文字符数（含空格）。C 类的系数来自 `recipes.ts` 的 `emWidth`：CJK 1 em、拉丁 0.55 em、空格 0.3 em，判据是 `emWidth(en)/emWidth(zh) ≤ 1.6`。
F 类不参与比值校验：`3 幕` 与 `20 slides` 本来就不同量级，比值没有意义，只要求「数字 + 最多 1 个单位」。

```text
├─ error.*           (9)       notConfigured · auth · network · timeout · badJson · aborted
│                              emptyOutline · schemaFailed · storeDegraded
├─ assemble.*        (7)       land · degraded · lock · tier.<l3|l2|l1|l0>
├─ gate.*            (19)      run · pass · warn · stuck · recast · count · fallback · still
│                              code.<11 个 lint code，名字与 LINT_CODES 逐字一致>
├─ premiere.*        (5)       start · again · back · edit · exit
├─ combo.count       (1)
├─ level.*           (2)       label · up
├─ unlock.new        (1)
├─ ach.<id>.name     (12)      id = 03 §6 的 12 个下划线 id
└─ settings.*        (12)      gameplay · gameplayMin · gameplayFull · autoPremiere · stream
                               sound · on · off · lockTier · tier · reset · resetConfirm
```

规则：**叶子必须是文案**（`string`），中间节点必须是对象；深度 ≤4 段；与 `LINT_CODES`、`RecipeId`、成就 id 对齐的键必须逐字同名（改名即测试失败）。
`settings.channel.*` 不再自建：通道预设归 [05](05-LLM接入规格.md) 的 `ai.panel.preset.*`，本文只登记文案（§2.8），避免两份同义键。

### 3.2 禁止写法

| 禁止 | 例 | 理由 |
|---|---|---|
| 中文/拼音 key | `forge.zh.开始生成` | 字典键即接口名 |
| 句子式 key | `forge.cast.theModelIsWriting` | 键描述位置，不描述内容 |
| 位置式 key | `forge.button.left`、`forge.topbar` | 布局会变，键不跟着变 |
| 序号式 key | `forge.stage.1` | 顺序会变，语义不保 |
| 重复前缀 | `forge.forge.cast` | 命名空间只写一次 |
| 下划线/连字符 | `forge.cast_stage`、`forge.deal-count` | 与现有 camelCase 不一致 |
| 全大写 | `forge.CAST` | 同上 |
| 控件后缀 | `forge.castBtn`、`forge.labelText` | 同一句话可能在按钮与气泡复用 |
| 复数变体 | `forge.deal.countOne` | 用同一 key + 数字（§6） |
| 五行深度 | `forge.a.b.c.d.e` | 扁平优先，超 4 段说明建模错了 |

### 3.3 与 `ai.zh.ts` 的复用 / 迁移关系

原则：**语气与字数完全一致就复用；字数或术语不同就新建 `forge.*`，旧键原地不动。**

| 现有 key | 现值 | 造幕台处置 | 理由 |

| `ai.panel.retry` | 重试（2 字） | **复用**（错误气泡按钮） | 2 字，动作一致 |
| `ai.panel.slideCount` | {count} 幕 | **复用** | 与 `forge.deal.count` 同值；造幕台直接读旧键，少一份同文案 |
| `ai.panel.preset.*`（6 条） | 本地 / DeepSeek / … | **复用** | [05](05-LLM接入规格.md) 已定键，新建设置页共用 |

## 4. 中英等长校验

### 4.1 判据

1. **主判据（自动）**：每个 C 类 key 计算 `emWidth(en)/emWidth(zh) ≤ 1.6`（尺见 `recipes.ts` 的 `emWidth`）。
2. **整数护栏（人工）**：C 类英文上限 `⌈2.9n⌉`；`n=6` 时是 **18 符**，而 1.6× 的整数解是 **17 符**——所以 **18 是报警线，17 才是实际可写到的位数**。
3. **豁免**：A/B 类按各自字符上限；D 类按 28 符；E 类品牌名；F 类计数器不参与比值。

### 4.2 超限词替换表（中文 ≤6 字、英文 >18 字符时怎么换）

| 中文 | 原英文（超限） | 换成 | 新长度 | 手法 |
|---|---|---|---|---|
| 文本溢出 | Text overflows the text box | Overflow | 8 | 删从句，留名词 |
| 对比不足 | Contrast ratio is below AA | Contrast | 8 | 术语替代（lint code 名） |
| 块数超限 | Too many blocks on this slide | Block count | 11 | 名词化 |
| 阅读过长 | Reading time exceeds the limit | Reading | 7 | 截取核心词 |
| 结构不符 | Output does not match the schema | Bad schema | 10 | 术语替代 |
| 未配端点 | No model endpoint is configured | No endpoint | 11 | 删系动词与冠词 |
| 密钥失效 | Your API key was not accepted | Key rejected | 12 | 被动式压缩 |
| 存档不可用 | Local storage is not available | Storage off | 11 | 状态词化 |
| 已兜底 | Fell back to a simpler layout | Fallback | 8 | 名词化 |
| 一小时内播放 | Play within one hour | One hour | 8 | 数字替代整句 |

通用手法（按优先级）：**删修饰 → 名词化 → 换术语表里的单词 → 数字替代 → 缩写（仅 L0–L3、Lv）**。

### 4.3 已知例外（登记，不掩盖）

2 字中文 + 术语表英文的例句。改词后 `重试 = Retry = 5 符 ≈ 2.75 em`，比值 **1.375×**，已回到 1.6× 之内；这类 key 仍归 **B 类**，按 00 §5 的「动作名 ≤8 字符」预算执行。

## 6. 数字与占位符

### 6.1 三个占位符

| 占位符 | 语义 | 约束 | 例 |
|---|---|---|---|
| `{count}` | 集合数量（幕数、处数、连击、重复次数） | 一个 key 内最多出现 1 次 | `{count} 幕`、`×{count}` |
| `{n}` | 序号或等级（第几幕、第几级） | 从 1 起算，不补零 | `Lv {n}` |
| `{done}` / `{total}` | 进度对 | 必须成对出现，`total` 恒为整数且 ≥ `done` | `{done}/{total}` |

`interpolate()` 的正则是 `/\{(\w+)\}/g`：**占位符名只允许字母、数字、下划线**；中文名、空格、`{0}` 位置参数都不生效（`{0}` 能匹配但没有同名变量，会原样输出）。

### 6.2 0 / 1 / 多的处理

中文不变形；英文按下表：

| 情形 | 英文写法 | 例 | 判据 |
|---|---|---|---|
| 该量恒 ≥2 | 可用可数名词复数 | `{count} slides`（幕数由 `normalizeOutline` 保证 ≥3） | 上游有 `min` 约束 |
| 该量可能为 0 或 1 | **不接名词**，只用数字或符号 | `{count}`（处数）、`×{count}`（连击） | `forge.gate.count`、`forge.combo.count` |
| 该量恒为 1 | 零数量词 | `Lv {n}` 里的 `Lv` 本身已是单数标记 | — |

一句话：**英文复数只赌"上游已保证 ≥2"的量**，其余一律把名词省掉。

### 6.3 计数器的写法

| 形态 | 写法 | 例 | 说明 |
|---|---|---|---|
| 进度 | 无空格、半角斜杠 | `3/9` | 禁止「第 3 幕，共 9 幕」这类句子 |
| 倍数 | U+00D7 紧贴数字 | `×4` | 不用字母 x |
| 增量 | 加号紧贴数字 | `+12` | 不带空格与单位 |
| 等级 | `Lv` + 1 空格 + 数字 | `Lv 7` | 禁止「等级 7」 |
| 数量 + 中文单位 | 数字 + 1 半角空格 + 单位 | `3 幕`、`12 处` | 单位不缩写 |
| 经验值 | `formatNumber()` 千分位 | `1,563` | 仅 xp 用千分位 |
| 编号 | 两位序号 | `01`、`02` | 卡面序号沿用 |

**禁止**：`%d`、`$1`、`{{count}}`、`{ count }`（空格不匹配正则）、`{count}个`（数字与单位之间留 1 空格）、中文数字（三幕 → 3 幕）。
