# LUMEN v0.2.0 · 产品化与造幕台设计交付包

> **这是什么**：v0.1.0 → v0.2.0 的完整设计与迭代计划。10 篇规格 + 1 张视觉样张 + 5 份可核对证据。
> **不包含什么**：不改 `src/**`、不提交、不上传、不联网。产物全部落在 `plan/v0.2.0/`。
> **一句话结论**：内核（管线 / 契约 / lint）已经够用，v0.2.0 要把「右栏表单」换成 **造幕台（Forge）**——一个整屏、可玩、动效由真实数据驱动、几乎不写字的生成界面；同时把 LLM 通道补到"真模型 / 可流式 / 可回放"。

## 6. 怎么用这套东西

1. **评审只拍板 §7.1 的 4 条**（§7 的 4 条已由本轮定掉），其余都是已定事实，不需要逐页过。
2. **实现从 T-01 / T-02 / T-05 起手**（[01](01-迭代计划.md) §3）：挂载、事件化、补 `enter` —— 这三件事做完，装台才有东西可动。
3. **不要在本轮改动 `src/schema/**` 与 `src/state/**`**：所有规格都按"零破坏性变更"写的，一旦动契约，`06` 的 fixtures 与 `07` 的基线全部作废。
4. **文案改一个字要同步 `09`**：字数上限是硬约束，`07` 有自动计数用例。
