## 1. 动效令牌

### 1.1 与现有令牌的关系：同值别名，只补两个缺

| 现有令牌 | 值 | 本文对应 | 关系 |
|---|---|---|---|
| `--ease`（`tokens.css` L46） | `cubic-bezier(.32,.72,0,1)` | `--fx-ease` = `var(--ease)` | **复用**，不重定义 |
| `--dur-fast`（L47） | 120ms | `--fx-t1` | 同值，语义升级为「阶梯第 1 级」 |
| `--dur`（L48） | 190ms | —— | 保留给 chrome hover；**不进**动效阶梯 |
| `--dur-slow`（L49） | 320ms | `--fx-t3` | 同值 |
| `slide.css` 入场 fade（L415） | 520ms | `--fx-t4` | 同值；落位 fade 直接对齐 |
| `slide.css` 入场 rise/scale（L418、L421） | 560ms | `--fx-t4x` | **继承值，不改**；只作为令牌引用 |
| `--play-ms`（`transitions.css`） | 200–800ms | 开演出口上限 | 沿用播放侧注入，不另设 |
| `--d-ease` / `--d-*`（deck 主题） | 运行时注入 | 不参与 | 造幕台只用 UI 令牌（`00` §2） |

结论：`--fx-*` **不是第三套体系**——7 个值是 `--dur*` / `slide.css` 的同值别名，新增只有 `--t2:220ms`、`--t4:520ms`、3 条缓动、2 档模糊、2 档亮度。

### 1.2 新增令牌

| 令牌 | 值 | 用途 | 唯一使用者 |
|---|---|---|---|
| `--fx-d1` | 8px | 火花起点、星标偏移、+1 首段 | Gate / Combo |
| `--fx-d2` | 16px | 卡片抬升、火花中段 | Deal / Gate |
| `--fx-d3` | 32px | +1 浮起、Gate 按钮入场 | Combo / Gate |
| `--fx-d4` | 64px | 台面落位下沉、开演收拢 | Assemble / Premiere |
| `--fx-t1` | `var(--dur-fast)` | 描边换色、火花收束 | 全段 |
| `--fx-t2` | 220ms | 翻面、星标出现、按钮 hover | Deal / Gate |
| `--fx-t3` | `var(--dur-slow)` | 阶段切换、按钮入场、升档 | Pulse / Gate / Combo |
| `--fx-t4` | 520ms | 落位 fade、开演出口 | Assemble / Premiere |
| `--fx-t4x` | 560ms | 落位 rise / scale（= `slide.css`） | Assemble |
| `--fx-ease` | `var(--ease)` | 进入、位移、落位 | 全段 |
| `--fx-ease-in` | `cubic-bezier(.4,0,1,1)` | **只用于离场**（内容退出） | Deal / Premiere |
| `--fx-ease-settle` | `cubic-bezier(.22,1,.36,1)` | 大距离快出慢停（落位、收拢） | Assemble / Premiere |
| `--fx-ease-pop` | `cubic-bezier(.34,1.42,.64,1)` | 轻微过冲，峰值 ≤1.08 倍 | Deal / Combo |
| `--fx-blur-1` | 6px | 卡面飞行运动模糊 | Deal |
| `--fx-blur-2` | 12px | T3 远景景深 | Assemble |
| `--fx-dim` | 0.82 | 卡住 / 未就绪的亮度 | Gate / Assemble |
| `--fx-lit` | 1.06 | 落位成功的瞬时提亮 | Assemble |
| `--fx-stagger` | 70ms | **兜底**错峰；真实值永远取 `block.enterDelayMs` | Deal / Pulse |
| `--fx-glow` | `0 0 0 1px var(--ui-accent-line), 0 8px 32px rgba(200,161,90,.16)` | 锁定角标、火花底光 | Deal / Gate |

```css
:root {
  /* 距离阶梯：位移只允许取这 4 个值 */
  --fx-d1: 8px;  --fx-d2: 16px;  --fx-d3: 32px;  --fx-d4: 64px;
  /* 时长阶梯：复用 --dur 体系，只补 220 与 520 */
  --fx-t1: var(--dur-fast);   /* 120ms */
  --fx-t2: 220ms;             /* 新增：一次操作 */
  --fx-t3: var(--dur-slow);   /* 320ms */
  --fx-t4: 520ms;             /* = slide.css enter-fade */
  --fx-t4x: 560ms;            /* = slide.css enter-rise/scale，继承勿改 */
  /* 缓动：1 条复用 + 3 条新增（离场 / 收停 / 过冲） */
  --fx-ease: var(--ease);
  --fx-ease-in: cubic-bezier(.4, 0, 1, 1);
  --fx-ease-settle: cubic-bezier(.22, 1, .36, 1);
  --fx-ease-pop: cubic-bezier(.34, 1.42, .64, 1);
  /* 光学：模糊 2 档、亮度 2 档 */
  --fx-blur-1: 6px;  --fx-blur-2: 12px;
  --fx-dim: .82;     --fx-lit: 1.06;
  --fx-stagger: 70ms;
  --fx-glow: 0 0 0 1px var(--ui-accent-line), 0 8px 32px rgba(200, 161, 90, .16);
}
```

### 1.3 三条禁令

| # | 禁令 | 理由 |
|---|---|---|
| 1 | 禁止在 `--fx-*` 之外写字面量时长/距离（`0.3s`、`12px`）；`@keyframes` 内的百分比位置除外 | 防止第三套体系偷偷长出来 |
| 2 | 不 animate `width/height/top/left/margin`；允许 `transform / opacity / filter / clip-path` | 只走合成层（`transitions.css` 同一纪律） |
| 3 | 同一帧内 `filter: blur()` 的元素 ≤4 个，L1 下为 0 | L1 的判据就是「没有模糊」（`00` §6.1） |

## 2. 六段动效脚本（对用户是五段：铸造与装台同屏）

**换算**：对外只有 5 个阶段点（起念 / 抽幕 / 铸造·装台 / 过检 / 开演），但"铸造"与"装台"在实现上是两个可分别观测的动效源——管线在跑（Pulse）与产物落下（`block.enter`）——所以内部按 **6 段**写脚本，DOM 也标 6 个值。5 与 6 的对应关系见下表，编号 `2.1`–`2.6` 与 6 个 `data-forge` 值一一对应。

| 对外 5 段（用户看到） | 内部 6 段（本节） | `data-forge` | 为什么拆开 |
|---|---|---|---|
| 起念 Seed | 2.1 Seed | `seed` | —— |
| 抽幕 Deal | 2.2 Deal | `deal` | —— |
| 铸造·装台 | 2.3 Cast | `cast` | 管线在跑：数据源是 `onStage`，画面上只有 Pulse 在动 |
| 铸造·装台 | 2.4 Assemble | `assemble` | 产物落下：数据源是 `block.enter`/`enterDelayMs`，画面是幕与块 |
| 过检 Gate | 2.5 Gate | `gate` | —— |
| 开演 Premiere | 2.6 Premiere | `premiere` | —— |

五段是同一台机器的五个状态，不是五套动画。**铸造 / 装台 / 过检 是同一条管线上的三段**：管线在跑（Cast）、产物落下（Assemble）、产物被审（Gate）。

| 段 | 进入触发 | 主数据源（唯一真相） | 主时长 | 出口 |
|---|---|---|---|---|
| 起念 Seed | `uiStore.mode='forge'` + 首帧 | 用户输入串（`input` 事件） | 交互驱动 | 提交 → `onStage('think')` |
| 抽幕 Deal | `composeOutline()` 返回 | `Outline.slides[].recipe`（12 选 1） | 12×70ms 发牌 | 点「开铸」→ `buildDeckFromOutline()` |
| 铸造 Cast | 管线开始 | `onStage(stage)` + `onProgress(done,total)` | 管线真实耗时 | 首幕 `done=1` → 装台 |
| 装台 Assemble | `onProgress(done,total)` 每次自增 | `slide.blocks[].enter` / `.enterDelayMs` | 卡面 320ms + 块 520/560ms（并行） | 全部 `done=total` |
| 过检 Gate | `lintDeck`（`slideIssues`）返回 | `issue.severity` + `issue.code` | 320ms + 用户动作 | 0 error → 开演 |
| 开演 Premiere | 「开演」或自动 | `slide.transition.kind` / `.ms` | 320ms + `--play-ms` | 全屏播放器 |

### 2.1 起念 Seed

| 动效 | 触发 | 数据源 | 时长 / 缓动 | L1 降级 | L0 |
|---|---|---|---|---|---|
| 光标呼吸 | 输入框聚焦 | `:focus-visible` | 2400ms 循环 / `ease-in-out` | 静止为 1 | 无 |
| 第 1 个字落定 | `value.length===1` | `input` 事件 | `--fx-t2` / `--fx-ease-pop` | 只做 opacity 0→1 | 直切 |
| 长句成形 | 中文 ≥12 字或拉丁 ≥24 字符 | 同上 | `--fx-t3` / `--fx-ease` | 直接给终点色 | 直切 |
| 提交脉冲 | 点「抽幕」 | `click` → `onStage('think')` | `--fx-t2` / `--fx-ease-in` | 同 | 直切 |

| 关键帧 | 0% | 40% | 100% |
|---|---|---|---|
| 第 1 个字落定 | `scale(1)` `opacity(1)` `filter(none)` | `scale(1.03)` `opacity(1)` `filter(brightness(1.06))` | `scale(1)` `opacity(1)` `filter(none)` |
| 长句成形 | `border-bottom-color: var(--ui-line)` | `var(--ui-accent-line)` | 同 40% |
| 提交脉冲 | `translateY(0)` `opacity(1)` `filter(none)` | `translateY(-8px)` `opacity(.35)` `filter(blur(2px))` | `translateY(-16px)` `opacity(0)` `filter(blur(6px))` |

> **不做**打字机效果。起念阶段的数据源是用户的手，不是模型 token；伪造 token 流违反 D2。

### 2.2 抽幕 Deal

| 动效 | 触发 | 数据源 | 时长 / 缓动 |
|---|---|---|---|
| 发牌 | `composeOutline()` resolve | 第 i 张卡，`delay = i × --fx-stagger` | 620ms / `--fx-ease-settle` |
| 翻面 | 该张落位结束 | 卡位 `i`；`delay = i×stagger + 500ms` | `--fx-t2` → `rotateY(180deg)` / `--fx-ease-pop` |
| 稀有度光泽 | 翻面完成 | `recipe ∈ {cover, closing}` → 金；`visual.kind==='three'` → 冷青 | `--fx-t4` 单向扫过 / `linear` |
| 首末锁定 | 首发与末发落位 | `outline.slides[0]` / `[n-1]` 的 `recipe` | `--fx-t3` / `--fx-ease` |

| 节奏参数 | 值 | 理由 |
|---|---|---|
| 错峰 `--fx-stagger` | **55ms**（12 张总长 660ms） | 70ms 会让 12 张排到 840ms，尾巴太长；55ms 仍在"看得出顺序"的区间（>40ms） |
| 单张时长 | 620ms（0%→40% 过冲到 1.02，40%→100% 收停） | 与 `--fx-t4x` 同量级；过冲只 2%，避免"弹一下" |
| 时间线形态 | **每条 WAAPI 时间线**（发牌/翻面/光泽各自 `delay`），不用 class + transition 的二次帧 | class 切换要等下一帧才能触发过渡，连排 12 张会看出"卡半拍" |

关键帧见 §6（卡面、排布、稀有度、锁定都集中在那里）。

### 2.3 铸造 Cast

铸造没有独立动画——**它就是 Pulse 本身**（§4）。管线在跑的时候屏幕上只有 Pulse 在动，别的都不许动。

| 约束 | 说明 |
|---|---|
| 数据源 | `onStage(stage)`（新增，见 §4.3）+ `onProgress(done,total)`（`compose.ts` L397 已存在） |
| 并发 | 管线并发 2（`compose.ts` L382 `runPool(...,2,...)`），所以「写作」阶段同时最多 2 幕在跑，Pulse 不假装单线程 |
| 禁止 | 不许出现假进度条、假 token、假"AI 正在思考"文案（`00` §7.6） |
| Mock | `MockProvider` 110ms 确定性 → 阶段会快速连跳，这是**正确**表现，不做人为拉长 |

### 2.4 装台 Assemble —— 落位动画 = 真实块的 `enter`

**硬规则**：幕卡落位后，块入场动画直接由该幕真实块的 `enter` + `enterDelayMs` 驱动（`deck.ts` L191–192，`slide.css` L415–423 已有实现）。造幕台**不另造一套假动画**，也不做二次插值。

| 落位子动作 | 数据源（字段，精确到来源） | 关键帧 0% | 40% | 100% | 时长 / 缓动 |
|---|---|---|---|---|---|
| 幕卡到位 | `onProgress` 第 `done` 次自增 | `translate3d(0,64px,-240px) scale(.92)` `opacity 0` | `translate3d(0,-8px,-60px) scale(.98)` `opacity .96` | `translate3d(0,0,0) scale(1)` `opacity 1` | `--fx-t3` / `--fx-ease-settle` |
| 块入场 `fade` | `block.enter==='fade'` | `opacity 0` | `opacity .92` | `opacity 1` | **520ms**（`slide.css` L416） |
| 块入场 `rise` | `block.enter==='rise'` | `translateY(18px)` `opacity 0` | `translateY(-3px)` `opacity 1` | `translateY(0)` `opacity 1` | **560ms**（L419） |
| 块入场 `scale` | `block.enter==='scale'` | `scale(.97)` `opacity 0` | `scale(1.004)` `opacity 1` | `scale(1)` `opacity 1` | **560ms**（L422） |
| 块错峰 | `block.enterDelayMs`（0–3000） | 直接作为 `animation-delay` | —— | —— | 原值，不改写 |
| 落位闷响环 | 同上 `done` 变化 | `scale(.6)` `opacity .5` 1px 环 | `scale(1.6)` `opacity .18` | `scale(2.2)` `opacity 0` | `--fx-t3` / `--fx-ease-settle` |
| 计数器 | `done/total` | `opacity .6` | `opacity 1` | 同 40% | `--fx-t1` / `linear` |

**真实的错峰值**（不是拍脑袋，取自 `recipes.ts`）：

| 配方 | 错峰来源 | `enterDelayMs` 实际取值 |
|---|---|---|
| `timeline` | `delay: index*70`（L738/747/759） | 0/70/140/210/280，5 节点 |
| `grid3` `grid4` | `delay: index*60`（L670/676/686） | 0/60/120（/180） |
| `compare` | `delay: index*60`（L826/837） | 0/60/120，左右各一列 |
| `process` | `delay: index*60`（L1066/1074/1082） | 0/60/120/180 |
| `data` | `delay: index*60`（L948/957） | 0/60/120/180 |
| `gallery` | `delay: index*60`（L1154） | 0/60/120 |
| `cover` `statement` `quote` `closing` `split` | 未设 `enter` | 全部 0（默认 `none`） |

| 预算口径 | 取法 | 说明 |
|---|---|---|
| 单幕落位动画时长 | **只看幕卡运动**：`--fx-t3` = 320ms，落在 `00` §6.2 的 220–420ms 内 | 块入场与卡面并行起播，属播放器同款表现，不另计时 |
| 掉帧统计窗口 | 卡面运动起止（320ms）内的 rAF 间隔 | 口径争议见 `## 未决` 1 |
| 进度真相 | 进度条宽度 = `done/total × 100%`，`transition: none` | 进度条永远不许比真实快 |

**`enter` 覆盖率缺口与兜底**：`06` 实测 v0.1.0 的块级 `enter` 覆盖率只有 **35.7%**——`cover` / `statement` / `split` / `quote` / `closing` 五个配方为 0（`recipes.ts` 里这些幕没有一处 `enter:`）。这意味着一半以上的幕**没有块级入场**，若装台只等 `block.enter`，那些幕会"啪"地出现。处置：v0.2.0 由 `01` 的 **T-05** 把覆盖率补到 ≥60%；**未补齐前，这些幕走「幕级入场」兜底**——即只用 §2.4 表格第一行（幕卡到位）的容器动效，**不伪造块动效**（不生成假 `enter`、不给块按延迟塞假动画）。兜底态的视觉判据：幕卡停稳即完成，`enter` 为 `none` 的块直接以终态出现。

## 3. 装台台面：L3 / L2 / L1 / L0

### 3.1 四档实现选择

| 档 | 实现 | 能用到的代码事实 | 切换判据 |
|---|---|---|---|
| **L3** three 台面 | 动态 `import('three')` + 幕卡贴图为平面网格，台面地板用 `plane` + 网格纹理 | `loadThreeModule()` 惰性加载（`runtime.ts` L104）；`MAX_LIVE_THREE_RUNTIMES=4`（L47）；`MAX_BACKING_PIXELS=4.2M` 自动降像素比（L49）；`suspend()` 先取 poster 再 `forceContextLoss()`（L384） | `isWebGLAvailable() && hardwareConcurrency≥4 && !navigator.connection?.saveData` |
| **L2** canvas 2.5D | 每幕离屏渲染一次 dataURL，`drawImage` 画平行四边形（顶边缩进 18%） | 复用 v0.1.0 已有依赖 `html-to-image`，**不新增**（D11） | 无 WebGL，或 L3 首帧 >32ms |
| **L1** CSS 流水线 | `perspective:1600px` + 每张卡 `translate3d/rotateX`，只动 `transform/opacity` | 与 `slide.css` 的 `mode='thumb'` 纪律一致（L447–455 关动画、关 3D canvas） | `prefers-reduced-motion`、`hardwareConcurrency≤2`、省电 |
| **L0** 静态切图 | 直接铺 poster（dataURL），`animation:none` | 同 `slide.css` L447 的 `thumb` 全禁套路 | 设置里「极简」、e2e 截图模式 |

**只降不升**（`00` §6.1）：一次判定写入 `forge.tier`，运行中不抖回去。运行中唯一的降档信号是**连续 2 幕**在落位窗口内掉帧 >2。

### 3.2 纹理与 dispose（代码事实 → 设计约束）

| 事实 | 位置 | 对造幕台的约束 |
|---|---|---|
| geometry/material/texture/renderTarget 全登记进 `ResourceBag`，`BuiltScene.dispose()` 统一释放 | `sceneBuilder.ts` L54–72 | 造幕台**不要**自己 dispose 材质；只保证 `runtime.dispose()` 被调用 |
| 同时活着 ≤4 个 runtime，超出最久未用的 `suspend()` 成 poster | `runtime.ts` L47、L126 | 造幕台 T2 只有**中心幕**吃 live runtime；左侧栈与右侧在铸幕都是 poster，永远碰不到上限 |
| `preserveDrawingBuffer: true` 常开 | `runtime.ts` L224 | 造幕台给 `pixelRatioCap: 1.5`，并在离开装台时 `disposeAllThreeRuntimes()`（L168） |
| 首帧先 `draw(0)` 画满 | L430 | L3 的「首帧 >32ms」必须在这一帧之后测量 |
| 缩略图模式绝不创建 WebGL | `slide.css` L453 | **T3 取景永远用 poster**，不建 runtime |

### 3.3 两种取景

**T2 — 台面主景（装台进行中，中心一幕 + 两侧叙事）**

## 4. 流程脉冲 Pulse：7 个状态

### 4.1 映射表（形态 + 位置 + 色相区分，不写字）

| # | 阶段 | 触发 | 数据源 | 视觉（默认无文字） | 时长 | 慢态文案（>1200ms 才出现） |
|---|---|---|---|---|---|---|
| 1 | 思考 `think` | 提交后第 1 帧 | `provider.complete` 已发出、未返回 | 单个 8px 圆点，2.4s 呼吸（`opacity .35↔1`） | 循环 | 无 |
| 2 | 大纲 `plan` | `onStage('plan')` | `composeOutline()` 请求中 | 1 点分裂成 3 点，沿 64px 轨道等距排开 | `--fx-t3` | 「排纲」/ Plan |
| 3 | 写作 `write` | 每幕 `provider.complete` | `onProgress` 前 `onStage('write',{slide})` | 轨道上 60% 宽的亮条平移到第 `slide` 格 | `--fx-t2` / 幕 | 「落字」/ Write |
| 4 | 画图 `draw` | visual 生成期 | `generateSvgArt` / `generateThreeScene` | 亮条变一条 `scaleY(0→1)` 的细线（12px 高） | `--fx-t2` | 「作图」/ Draw |
| 5 | 排版 `set` | `buildRecipe()` 前 | `onStage('set',{slide})` | 细线折成 3 段等距短杠 | `--fx-t1` | 「定版」/ Set |
| 6 | 过检 `check` | `slideIssues()` 前后 | `onStage('check',{slide})` | 短杠收成圆环，顺时针扫 1 圈（`conic-gradient` 旋转） | `--fx-t3` | 「过检」/ Check |
| 7 | 收尾 `seal` | 落库 + `historyOps.transaction` | `onStage('seal')` | 圆环闭合，下沉 `--fx-d1`，色 `--ui-accent` → `--ui-accent-2` | `--fx-t2` | 「收尾」/ Seal |

**不写说明文字**：7 个状态靠三件事区分——**形态**（点 / 点阵 / 条 / 竖线 / 短杠 / 环 / 闭合环）、**位置**（时间轴上的格位）、**色相**（`--ui-accent` 进行中，`--ui-accent-2` 完成）。文字只在「慢态」兜底出现，同一时刻最多 1 个 Pulse 文字元素。

### 4.2 三条规则

| 规则 | 内容 |
|---|---|
| 慢态阈值 | 同一阶段停留 >1200ms 才显示 2 字标签；推进即消失。1200ms 是"人开始怀疑卡住"的粗略阈值 |
| 不许跳级编造 | 观察不到的阶段直接跳过（非流式 provider 不产生 token → `write` 内部不做子状态）。跳级是正确信息 |
| 中英等长 | 视觉宽度按「1 汉字 ≈ 2 拉丁字符」折算：「排纲」≈4 列，`Plan`=4 列，1.00×，满足 D10 |

### 4.3 实现：一个进度量，不是七次跳变

上表描述的是**七个可辨认的形态**，不是七次硬切。实现上只有**一个标量** `prog ∈ [0,7]`，由**一条 rAF 曲线**推进（`easeOutCubic`，320–620ms 一段），七根柱子的高度/颜色只是 `clamp(prog − i, 0, 1)` 的读数：

- 装台期间 `prog` 从 2 连续推到 5（`2 + 3 × done/total`），不再"每幕闪四下"；
- 过检失败时 `prog` 停在 5.6，第 6 根换成红色缺口（`markBad()` 必须先清掉 rAF 写的行内样式，否则类选择器会被盖掉）；
- 收尾推到 6.4 后所有柱子落为 `--ui-accent-2` 的完成态。

这就是"更流畅"的具体含义：**同一件事只允许一条时间曲线**。七次 `setTimeout` 硬切会让 42U 以下的小屏看出明显顿挫，也会让读屏连播七条状态。

| 反模式 | 症状 | 正确做法 |
|---|---|---|
| 每阶段一次 `setTimeout` 换 class | 柱子"跳"，快机型上看不出中间态 | 单 rAF + 单标量 |
| 柱高既用 CSS `transition` 又用 rAF 写 | 双重缓动，末端发肉 | 只留 rAF，CSS 关掉 `transition` |
| 每次 `onProgress` 重启动画 | 并发 2 时两幕互相打断 | 目标值单调递增，只改终点不重启动画 |

### 4.4 唯一新增契约

`compose.ts` 目前只有 `onProgress`（L397），没有阶段回调。本文把 `onStage` 列为**唯一新增接口**，且不改任何数据结构（`00` §2 已允许「只加阶段回调」）。

```ts
export type ForgeStage = 'think' | 'plan' | 'write' | 'draw' | 'set' | 'check' | 'seal'

export interface StageEvent {
  stage: ForgeStage
  slide?: number   // 1-based 幕号，仅 write/draw/set/check 有
  done?: number    // 复用 onProgress 的计数真相
  total?: number
  at: number       // performance.now()
}

// BuildDeckOptions 上新增（可选，不传则行为与 v0.1.0 完全一致）：
//   onStage?: (event: StageEvent) => void
```

## 5. 过检 Gate：三种反馈与时序

### 5.1 三档

| 结果 | 是否需要人 | 视觉 | 文案（≤6 字） | 阻断 |
|---|---|---|---|---|
| `error` | 是 | 两道门线转 `--ui-danger` + 幕停在门中间 + 8 束放射状金色短线 + 幕右上 `!` 角标 + 「重铸」 | 「重铸」 | 阻断该幕开演 |
| `warn` | 否 | 幕右上 6px 四角星（`scale 0→1`，`--fx-t2` / `--fx-ease-pop`） | 无 | 不阻断 |
| `info` | 否 | **无视觉** | 无 | 不阻断 |

`info` 也要留证据：只写进导出前清单与读屏 `aria-live="off"` 通道，不上屏。

### 5.2 「门」是全屏装置，不是幕的边框

过检的空间语言：舞台上有**两道 1px 竖线**当门——间距 160px（`translateX(±80px)`），从顶栏下方一直贯穿到底部 Pulse，**不属于任何一张幕**。幕从台面上被推到门中间停住（`translateZ(200px) scale(.96)`），门的线可以压在幕上，读法才是"穿过门"，而不是"幕有个边框"。

| 门的状态 | 颜色 | 触发 |
|---|---|---|
| 正常 | `--ui-accent`（金），`box-shadow: 0 0 16px rgba(200,161,90,.4)` | 进入过检、`error` 数为 0 |
| error | `--ui-danger`，`box-shadow: 0 0 20px rgba(228,87,79,.55)` | `slideIssues()` 返回 ≥1 个 `error` |
| 收束 | 回金，120ms（`--fx-t1`） | 重铸成功 |

### 5.3 error 的完整时序（相对 lint 返回的 t=0）

| t | 事件 | 具体属性 |
|---|---|---|
| 0 | 卡住 | 幕 `filter: brightness(.88) saturate(.72)`；门色 120ms 内 `--ui-accent → --ui-danger`；Pulse 第 6 格（`check`）变红色缺口 |
| 0 | 顶到门前 | 幕 `translateZ(0) → translateZ(200px)`、`scale(1) → scale(.96)`，`--fx-t3` / `--fx-ease-settle` |
| 0 | `!` 角标 | 幕内右上 6px **方形**（`border-radius: 0`），`scale(0→1)`，`--fx-t2` / `--fx-ease-pop`；不用圆形，圆形会被读成状态点 |
| 40–320 | 金色短线爆开 | 8 束，落在**贴着幕外沿的椭圆轨道**（`rx 470 / ry 300`，即 800×450 幕的 ±70 外扩），角度均匀、长度 12/18/24px 三档、越远越淡（`opacity 1→.68`），像火花爆开的一帧 |
| 320 | 「重铸」入场 | 幕下方**只有一个按钮**，`translateY(--fx-d3) opacity 0` → `0 / 1`，`--fx-t3` / `--fx-ease`；旁边**不放任何孤立数字** |
| 用户点击 | 收束 | 短线 120ms 内消失；幕降到 `brightness(.5) saturate(.4)`；Pulse 回 `check`；按钮 `disabled` 但保持尺寸（不抖动） |
| 成功 t' | 恢复 | 门回金；幕回 `brightness(--fx-lit 1.06)`（40% 处）；金色扫光 520ms 从左到右（`clip-path: inset(0 100% 0 0) → inset(0)`）；`!` 角标淡出 |
| 失败 t' | 再次卡住 | **不重复爆开**，只把门线闪 2 次（120ms 亮/暗）；第 2 次失败后按钮右侧出现「改稿」入口 |

### 5.4 短线实现约束

| 项 | 值 |
|---|---|
| 元素 | 8 个 `span`（不用 canvas / 不用 SVG），`position:absolute`，`pointer-events:none` |
| 轨道 | 椭圆 `x = cos θ × 470`、`y = sin θ × 300`，`θ = 45°×i + 13.8°`（错开四角，避免读成"四个箭头"） |
| 朝向 | 短线沿法线朝外：元素底端锚在轨道点，`transform: rotate(θ + 90°)`，`transform-origin: 50% 100%` |
| 尺寸 | 长 12 / 18 / 24px（`i%3`）、粗 1px、末端 1px 圆头 |
| 色 | `--ui-accent` 渐变到透明；L1 下减到 4 束、无渐变 |
| 锚点 | 椭圆恒以**幕中心**为心；若 `issue.blockId` 可取，短线整体偏移到该块（偏移量 ≤ 幕半径的 40%，否则回落到幕心） |

| 1 | 最后一幕落位完成 | `onProgress(done===total)` | —— |
| 2 | 中心幕从 `z 0` 收到弧线中位，其余幕同时归位 | 每幕的 `index` | `--fx-t4x` / `--fx-ease-settle` |
| 3 | 压上径向暗角，只留中央 40% | —— | `--fx-t4` |
| 4 | 「开演」+「回编辑器」入场 | `forge.autoPremiere` | `--fx-t3` / `--fx-ease` |

### 8.2 出口二：T3-a → 全屏播放器（与 `transitions.css` 的 5 种衔接）

| `slide.transition.kind` | 造幕台出口动作 | 衔接的 keyframes | 时长 |
|---|---|---|---|
| `fade` | 台面整层 `opacity 1→0`，底下 `#000` | `play-fade-in` | `--fx-t3` + `--play-ms` |
| `push` | 台面 `translate3d(-100%,0,0)`，方向由首幕是否 `index>0` 决定 | `play-push-in-fwd/back` | 同上 |
| `wipe` | 台面 `clip-path: inset(0 100% 0 0) → inset(0)` | `play-wipe-in-fwd` | 同上 |
| `flip3d` | 台面 `rotateY(90deg)`，容器 `perspective:2400px`（与播放器同值） | `play-flip-in-fwd` | 同上 |
| `none` | 直切 | 无 | `--fx-t1` |

**接缝纪律**：出口动画的**结束状态**必须逐属性等于播放器第 1 帧（`data-phase='in'` + `data-transition`）。做法：出口在 `--fx-t3` 跑完的同时 `play:mounted`，播放器从终点接管 `opacity/transform`。任一属性不相等就会出现"闪一下"，这是本节唯一的验收点。

`prefers-reduced-motion` 下两边都退化为 120ms 淡入——`transitions.css` L234–244 已有这条分支，造幕台出口直接复用同一时长。

### 8.3 自动进开演（T2 完成 → T3-a）

| 项 | 内容 |
|---|---|
| 开关 | `forge.autoPremiere`（默认 **开**，与 D3 的"默认开"同风格；也可视为 D3 的延伸，`03` 可复核） |
| 触发 | 最后一幕 `done===total` 后，等 `slide.transition.ms`（`compose.ts` L192 默认 420ms） |
| 关掉后 | 停在 T3 完成态，只留「开演」按钮，不自动全屏 |
| 取消 | 420ms 窗口内任何 `pointerdown` / `keydown` / `wheel` → 取消本次自动进入（无障碍：不给人突然全屏） |
| 读屏 | 自动进入前只播报 1 次「4/9 收尾」，不逐幕播报（见 §10.3） |

### 8.4 门户 → 工作台（入口转场）

门户（Portal）是造幕台之外的一层，指向它的唯一动作是「进入工作台」。这一跳只做一件事：**让幕从"散开的三张"收成"将要生成的那一张"**，衔接的是造幕台的 Seed 首帧，不是播放器。

| 步 | 动作 | 时长 / 缓动 | 数据源 |
|---|---|---|---|
| 1 | 三张幕卡向屏幕中心收拢（`translate3d` 归零 + `scale .86` + `opacity 0`），错峰 40ms | 420ms / `--fx-ease-in` | 卡片索引 |
| 2 | 标题与主按钮上移 8px 淡出 | 260ms / `--fx-ease-in` | —— |
| 3 | 整页淡出 | 240ms / `linear`，delay 260ms | —— |
| 4 | 造幕台挂载（`data-forge='seed'`），起念输入框拿到焦点，光标呼吸起播 | `--fx-t3` 后 | `uiStore.mode='forge'` |

| 约束 | 内容 |
|---|---|
| 不留白 | 门户不卸载，用交叉淡出（造幕台 220ms 淡入压在上面），任何时刻都有东西可看 |
| 可中断 | 转场期间任何输入不取消（总长 560ms，取消反而更突兀） |
| 反向 | 造幕台「回门户」走同一条曲线反向 320ms，不另做一套 |
| 减少动效 | 只保留 120ms 交叉淡入，卡片不做收拢 |

## 9. 音频（5 类轻音，默认关）

| 事件 | 触发点（代码） | WebAudio 合成 | 包络（attack/decay） | 时长 | 峰值 |
|---|---|---|---|---|---|
| 抽卡 | 每张牌落位（12 张最多叠 4 声，60ms 内合并） | `triangle` 520→660Hz，`detune` 随机 ±30 音分 | 4ms / 90ms | 90ms | −22dBFS |
| 落位 | `onProgress` 每次自增 | `sine` 132→98Hz + 6ms 噪声脉冲 | 4ms / 120ms | 120ms | −20dBFS |
| 过检 | error：`square` 220Hz 双脉冲 + 30ms 噪声；ok：`sine` 880 与 1320 相隔 70ms | 4ms / 140ms | 140 / 160ms | −24dBFS |
| 连击 | `combo.count` 自增 | `sine`，基频 `660 × 2^(n/12)`，`n=min(count,12)` | 4ms / 60ms | 60ms | −26dBFS |
| 开演 | 进入 premiere | 琶音 523 / 659 / 784，间隔 70ms（= `--fx-stagger`） | 8ms / 240ms | 240ms | −20dBFS |

| 项 | 决定 |
|---|---|
| 文件 | **零音频文件**：只用 `OscillatorNode` + `GainNode` + 1 段 `AudioBuffer`（噪声，运行时生成 30ms 白噪） |
| 图 | 1 个 `AudioContext` → `DynamicsCompressor` → master `GainNode(0.22)`；节点 `stop(t)` 后 `disconnect()`，不常驻 |
| 默认 | **关**（D6）。首次开启必须由用户手势触发 `ctx.resume()`（自动播放策略） |
| 音量 | 峰值 ≤ −20dBFS，master 0.22，实测 LUFS ≤ −18（用 `07` 的响度用例核） |
| 减少动效 | `prefers-reduced-motion` **不改变**音频（动效与声音是独立偏好）；`visibilitychange → hidden` 时 `ctx.suspend()` |
| 节流 | 同一事件 60ms 内最多 1 声；`ctx.state !== 'running'` 时静默失败，不排队 |
| 交互 | 一个 1.5 字宽的图标按钮（喇叭），不写文字；开启态图标 `--ui-accent` |

### 10.2 `prefers-reduced-motion`：不消失，只换形态

| 动效 | 原形态 | 替代形态（**保留信息**） |
|---|---|---|
| 发牌 70ms 错峰 12 张 | 位移 + 旋转 + 模糊，840ms 总长 | 一次性全部 `opacity 0→1` 120ms，**顺序信息**改由卡面 bracket 的先后点亮表达（每张 24ms） |
| 翻面 | `rotateY 180°` | `opacity` 交叉淡入 120ms + `scale(1.01)` |
| 台面 3D 落位 | `translate3d` + 景深 | `translateY(8px)` + `opacity`，120ms；纵深改用 `opacity` 梯度（前 1 / 后 .72 / 第三 .5） |
| 块入场 rise/scale | 18px 位移 / .97 缩放 | 只 `opacity`，`--fx-t1`；`enterDelayMs` 保留（信息不变） |

| Gate 火花 | 8 束抛射 | 火花改成**静态**8 射线，`opacity` 呼吸 1 次（120ms 亮）——「出错了」的信息保留 |

| 开演出口 | 320ms 位移/裁剪 | 120ms 淡入（与 `transitions.css` L234 一致） |

原则：**降的是运动幅度与时长，不降"发生了什么"**。

### 10.3 `aria-live` 节流

| 通道 | 节点 | 内容 | 节流 |
|---|---|---|---|
| 阶段 | 1 个 `role="status" aria-live="polite" aria-atomic="true"` | 「装台 3/9」这种「阶段 + 计数」 | 500ms 合并窗口：窗口内多次变化只播最后一次 |
| 错误 | 1 个 `role="alert"` | 「第 4 幕 溢出 · 重铸」 | ≤1 次/秒；连续 error 只播第一条（后续改成计数「2 处」） |
| 连击 | `aria-live="off"` | 只写进可查询的 DOM 属性，不播报 | 永不主动播报 |
| 完成 | status 通道 | 「9/9」 | 1 次 |

禁止：不要把 `+1`、每次 `onProgress`、每张牌落位都塞进 live region——读屏会被刷屏，这是最常见的无障碍事故。

### 10.4 焦点与键盘

| 位置 | 行为 |
|---|---|
| 进入造幕台 | 焦点落 `input`（起念）；`role="dialog" aria-modal="true" aria-label="造幕台"` |
| 抽幕 / 开铸 / 重铸 / 开演 | 均为真 `<button>`，`Enter`/`Space` 触发；动词标签 ≤3 字（`00` §7.3） |
| 12 张牌 | `role="listbox"` + **roving tabindex**：`←/→` 移一格，`Home/End` 首末，`Enter` 选中；不把 12 个 tab stop 塞进 Tab 序列 |
| 装台 | **不可聚焦**（纯展示）；`aria-hidden="true"` 包整层，避免读屏走进 9 幕的块海 |
| 过检错误项 | `role="list"`，错误项可聚焦；焦点到某幕时 `aria-describedby` 指向该 code 的短句 |
| 开演 | `Escape` 退出播放回造幕台（与现播放器一致）；退出后焦点回到「开演」按钮 |
| 关闭造幕台 | `Escape`（D12：立刻落库已完成幕，不询问） |
| 减少动效 | 不改变焦点路径（动效降级不得改变 Tab 顺序） |

### 11.2 测量契约

```ts
// 1) 长任务：整个造幕台生命周期只挂一个 observer
const longTask = new PerformanceObserver((list) => {
  for (const e of list.getEntries()) forgeMetrics.longTasks.push(e.duration)
})
longTask.observe({ type: 'longtask', buffered: true })

// 2) 落位掉帧：只在卡面运动窗口内采样（窗口外的不算）
function sampleLanding(ms = 320) {
  const gaps: number[] = []
  let last = performance.now()
  const end = last + ms
  const tick = (t: number) => {
    gaps.push(t - last); last = t
    if (t < end) requestAnimationFrame(tick)
    else forgeMetrics.landing.push({ gaps, dropped: dropped(gaps) })
  }
  requestAnimationFrame(tick)
}
// dropped(): 帧长 > 1.5 × 中位帧间隔的帧数

// 3) 首屏
performance.mark('forge:mount')      // enter() 第一行
performance.mark('forge:interactive') // 起念输入可输入 + Pulse 首帧已画
performance.measure('forge:boot', 'forge:mount', 'forge:interactive')
```

```ts
// 4) Playwright：three 必须 lazy，且不在首屏请求
const chunks: string[] = []
page.on('request', (r) => { if (/three/i.test(r.url())) chunks.push(r.url()) })
await page.goto(forgeUrl)
await page.waitForSelector('[data-forge=\'seed\']')
expect(chunks).toHaveLength(0)                 // 首屏不得有 three
await page.click('[data-fx=\'action\']')       // 进入装台
await expect.poll(() => chunks.length).toBeGreaterThan(0) // 装台才加载
```

### 12.4 名词对照：界面用「一眼明白」，代号留在代码里

`00` §5 与 `09` 定的是**代号**（铸造 / 装台 / 过检 / 开演 / 抽幕 / 开铸 / 重铸），它们同时是代码标识（`cast` / `assemble` / `gate` / `premiere` / `deal`）。代号适合内部沟通，但**不适合直接当按钮**——「开铸」对第一次用的人不成立。样张自 mock.2 起把**界面文案**换成标准名词，代码标识一字不动：

| 位置 | 代号（00/09 + 代码） | 界面标准名词（样张） | 长度 |
|---|---|---|---|
| 第 1 段 | 起念 `seed` | **输入** | 2 |
| 第 2 段 | 抽幕 `deal` | **大纲** | 2 |
| 第 3 段 | 铸造 + 装台 `cast`+`assemble` | **生成** | 2 |
| 第 4 段 | 过检 `gate` | **检查** | 2 |
| 第 5 段 | 开演 `premiere` | **播放** | 2 |
| 主按钮 1 | 抽幕 | **生成大纲** | 4 |
| 主按钮 2 | 开铸 | **开始生成** | 4 |
| 主按钮 3 | 重铸 | **重试** | 2 |
| 主按钮 4 | 开演 | **播放** | 2 |
| 退出 | 回编辑器 | **回门户** | 3 |

| 取舍说明 | 内容 |
|---|---|
| 为什么两个按钮超 4 字 | 「生成大纲 / 开始生成」把两步区分开；若压缩到 3 字（如「出纲」「开铸」）歧义立刻回来。两条都 ≤4 字，仍在"按钮一眼读完"的区间 |
| 代号去哪了 | 留在 `00` §5 术语表、`09` 的 i18n key（`forge.deal.cast` 等）与本系列文档里；界面不再出现 |
| 待办 | 这条替换需要 `09` 同步改词表，见 `## 未决` 3 |

### 12.5 门户（Portal）

门户是造幕台之外新增的一层，`02` 目前没有覆盖它（`02` §2.1 的 4 个入口都在编辑器内部）。样张先给一个可看的样子，**信息架构以 `02` 补章为准**。

| 区块 | 内容 | 动效 |
|---|---|---|
| 顶栏 | 品牌 `LUMEN / 幕光` + 版本 + 「设置」 | 静态 |
| 主区左 | 一句话主张（56px）+ 一行副题 + 「进入工作台」（accent 主按钮） | 进入时上浮 8px / 320ms |
| 主区右 | 三张 420×236 的幕（`rotateY ±16°`、z 各 -110/40/-110、9s 浮动） | hover 抬 10px、转正、亮边；点击即走 §8.4 的收拢转场 |
| 设置抽屉 | 通道 / 模型 / 台面档位 / 声音 / 减少动效 / 语言 / 快捷键 | 右侧滑入 320ms `--fx-ease-settle`，scrim 300ms 淡入 |
| 文字预算 | 首屏 6 个元素：品牌、版本、主张、副题、「进入工作台」、「设置」；扇形卡不写字 | —— |

| 与造幕台的关系 | 内容 |
|---|---|
| 设置联动 | 抽屉写 `lumen.prefs`；造幕台启动读取 `tier` 与 `audio`——**门户里选的档位，进去就生效** |
| 回程 | 造幕台「回门户」→ `portal.html`，走 §8.4 的反向曲线 |
| 不做什么 | 不做账号、最近项目列表、云同步（`00` §3.2 的边界不变） |
