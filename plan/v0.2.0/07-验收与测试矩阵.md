# 07 验收与测试矩阵

> 职责：把 v0.2.0 的每条能力拆成「另一人照做就能判过/不过」的条目，并落到现有 vitest / Playwright / 截图 harness 三层，外加本文件新增的 perf / a11y / offline 门禁。
> 上游：`00-范围与决策.md`（§3 边界、D1–D12、§6 预算、§7 文案）；下游：`08-发布清单.md`（发版门禁直接引用本文 §2 与 §9）。

---

## 1. 读法与基线

| 记号 | 含义 |
|---|---|
| `F` `G` `L` `D` `A` `R` | 分组：造幕台 / 游戏化 / LLM 通道 / 降级与性能 / 无障碍与文案 / 回归与失败路径 |
| `+新建` | v0.2.0 需要新增的文件，**落地前不存在**；不带此标记的路径在 v0.1.0 已存在 |
| 过 | 按「步骤」操作后，「预期」里的可观测事实全部成立；任一条不成立即为该 ID 红 |
| 采样 | 单测 2026-10-28 实测 9 文件 / 183 用例（约 1.6s）；e2e 5 spec / 10 用例（约 46s）；数字随并行开发漂移，以实跑输出为准 |

三条铁律：

1. 判据必须机器可读或二值可判（DOM 计数、请求数、毫秒、字节、页数、文件名）。「体验良好」「动效自然」一律不算判据。
2. 阈值只引用 `00 §6.2`，本文件不另立第二套标准；发现新指标先改 `00`，再进矩阵。
3. 一条用例失败 = 一个 ID 红；ID 不合并、不跳过。`test.skip` 等于删除验收，`test.fixme` 同理。

### 2.1 七层

| 层 | 位置 / 工具 | 跑什么 | 时长 | 阻塞发版 |
|---|---|---|---|---|
| unit | `tests/unit/*.test.ts`（vitest + jsdom，`vitest.config.ts`） | 纯逻辑：配方、schema、lint、计分、replay 解析、错误映射、文案字数 | 现 1.6s，目标 ≤ 20s | 是 |

| e2e | `tests/e2e/*.spec.ts`（Playwright，`workers: 1`，5274） | 造幕台五段、键盘全流程、错误与降级、导出/打印回归 | 现 46s；新增 15 spec，全套目标 ≤ 8min | 是 |

| perf | `tests/e2e/perf-budget.spec.ts` + `performance.mark` / `longtask` / CDP heap | 首屏 400ms、长任务 50ms、掉帧、JS 体积、three lazy、内存 | ≤ 60s | 是 |
| a11y | `tests/unit/forge-copy.test.ts` + `tests/e2e/forge-a11y.spec.ts` | 字数/感叹号/中英等长、键盘全流程、焦点陷阱、aria-live 节流、对比度 lint | ≤ 40s | 是 |

integration 落在 `tests/unit/**` 是刻意的：`vitest.config.ts` 的 `include` 只有 `tests/unit/**/*.test.{ts,tsx}`（Lead 所有，本轮不动），另立 `tests/integration/` 会让 `pnpm test` 静默漏跑这些用例。`05 §13.2` 另要求一层 `tests/unit/contract/replay.test.ts`，同样卡在这条 `include` 上，落地方式见 §10-2；定稿后它并入 G2 门禁。

## 7. 性能与体积用例

### 7.1 采样口径

| 指标 | 采集方式 | 阈值（= `00 §6.2`） |
|---|---|---|
| 首屏可交互 | `measure('forge:boot', 'forge:mount', 'forge:interactive')` | ≤ 400ms（中位数；单次 ≤ 450ms） |

### 7.2 断言模板

### 7.3 体积核对（可复制）

```powershell
$entry = (Select-String -Path dist/index.html -Pattern 'assets/(index-[^"]+\.js)').Matches[0].Groups[1].Value
$path  = Join-Path dist "assets/$entry"
$ms    = New-Object System.IO.MemoryStream
$gz    = New-Object System.IO.Compression.GZipStream($ms, [System.IO.Compression.CompressionMode]::Compress, $true)
$bytes = [System.IO.File]::ReadAllBytes($path)
$gz.Write($bytes, 0, $bytes.Length); $gz.Dispose()
"entry=$entry gzip={0}KB budget=285.1KB" -f [math]::Round($ms.Length / 1KB, 1)
```
