## 1. 这一轮到底改了什么（一句话版）

v0.2.0 已经有「落位、闷响环、扫光、Pulse 七柱、粒子、火花、弧线」，但它们是**一次性的、不分档的**；
v0.2.5 把同一批装置接上 `prog` 与 `done` 两个真实读数，并给每条都补一张**四档回落表**：

| # | 效果 | 这一轮的新增 | 落在哪 |
|---|---|---|---|
| FX-1 | 落位冲击波 `ring` | 新增 520ms 扩散环 + L3 外环；与 v0.2.0 的 320ms 闷响环**并存** | `forge.css` `.forge-stage__shock`、`Assemble.tsx` |
| FX-2 | 完成栈深度 | `--forge-depth` 从行内深度读出，L3 走 `translateZ(-i·18px)` + 逐层降亮的过渡 | `Assemble.tsx`、`forge.css` |
| FX-3 | Pulse 环形进度 | SVG 环 + `pulseRingOffset()` 纯函数；L1/L0 线性/静态条 | `hud/Pulse.tsx`、`forge.css` |
| FX-4 | 环境粒子随进度加速 | `ambientSpeed(prog)` 1.0→2.2、`setProgress()`、落位 `rip()`（rAF 内衰减） | `fx/ambient.ts`、`Assemble.tsx` |
| FX-5 | 开演席卡片扫光 | 纯 CSS `::after` 扫光 + 40ms 错峰（`--i` 由结构位置给出） | `forge.css` |
| FX-6 | 过检火花密度 | 束数按档位 12 / 6 / 3 / 0 | `stage/Gate.tsx` |
| FX-7 | 完成收束 | L3 弧线 620ms 合拢；L2/L1 320ms 只收不透明度 | `forge.css`（触发 = `deck:done`） |

**没做的事**：没有新增 DOM 节点层级（FX-1 的 `ring` 是舞台内的一枚 `span`，与既有 `.forge-stage__ping` 同级；
FX-3 的环是 `Pulse` 内部的两个 `span`）；没有新增文字；没有把 v0.2.0 的任何动画删掉或改时长。

## 2. 令牌增量（`forge.css` 的 `.forge` 块）

`04` §1.3 的三条禁令继续有效：**不在 `--fx-*` 之外写字面量时长/距离**。本轮只补 6 个具名值，
全部是既有阶梯的延长，不新立第三套体系：

```css
.forge {
  --fx-ring: 520ms;          /* FX-1 冲击波（= slide.css 的 enter-fade = --fx-t4） */
  --fx-ring-fade: 120ms;     /* FX-1 · L1 只淡出（= --fx-t1） */
  --fx-close: 620ms;         /* FX-7 弧线合拢（= 04 §6.4 发牌时长） */
  --fx-sweep: 640ms;         /* FX-5 单张扫光 */
  --fx-card-stagger: 40ms;   /* FX-5 错峰（02 §6.1 的 40ms） */
  --fx-depth-z: 18px;        /* FX-2 每层纵深 */
}
```

缓动一律复用 `04` §1.2 已有的三条：`--fx-ease`（进入）、`--fx-ease-settle`（大距离快出慢停）、
`--fx-ease-pop`（轻微过冲），`linear` 只用于纯淡出与扫光。

## 3. 触发契约：真实事件 → 状态 → DOM/CSS（本文的证据列）

所有 FX 的「第 0 毫秒」都必须能在下表里找到一行。`state.ts` 的 reducer 是唯一写状态的地方，
`Assemble/Gate/Pulse/Premiere` 只读。

| # | 帧 | 真实事件（`ForgeStageEvent`） | reducer 落点（`state.ts`） | 读到的状态 | DOM / CSS 落点 |
|---|---|---|---|---|---|
| FX-1 | 冲击波起播 | `slide:landed` | `stageEvent` 分支：`status='landed'`、重算 `done`、`active=event.index` | `done`（`Assemble` prop） | `Assemble.tsx`：`<span className="forge-stage__shock" key={`shock-${done}-${active}`} data-forge-shock={done}/>`；CSS `.forge-stage__shock` |
| FX-2 | 栈深递进 | `slide:landed`（`done` 自增） | 同上（`done` 只在此自增） | `done` + `stack[depth]` | `.forge-assemble__stack[data-forge-depth]`；每层 `.forge-assemble__thumb { --forge-depth: depth }` |
| FX-3 | 环推进 | `stage`（7 个阶段）+ `slide:landed`（`2 + 3·done/total`）+ `deck`（6.4） | `STAGE_PROG` / `slide:landed` / `deck` 分支写 `prog` | `prog`（`Pulse` prop） | `Pulse.tsx`：`strokeDashoffset={pulseRingOffset(prog)}`；CSS `.forge-pulse__ring-arc` |
| FX-4 | 速度爬升 | 同 FX-3（`prog`） | 同 FX-3 | `deriveProg(stage, done, total)` | `Assemble.tsx` 的 `useEffect([prog])` → `handle.setProgress(prog)` |
| FX-4 | 一次 rip | `slide:landed` | 同 FX-1 | `done` 自增 | `Assemble.tsx` 的 `useEffect([done])`：`if (done > prevDone) rip()` |
| FX-5 | 扫光起跑 | `deck:done` | `deck` 分支：`phase='premiere'` | `forgeMark(state)==='premiere'` → `data-forge='premiere'` | CSS `.forge-premiere__card::after`（父级已是 premiere 屏） |
| FX-6 | 火花束数 | `gate` 屏（`slide:gate` 写入 `errors`） | `stageEvent` 的 `slide:gate` 分支 | `bad`（`errors.length>0`）+ `tier` | `Gate.tsx`：`raysOf(sparkCount(tier))`；`data-forge-sparks={rays.length}` |
| FX-7 | 收束起播 | `deck:done` | 同上（`phase='premiere'`、`premiereAt`） | `data-forge='premiere'` | CSS `.forge[data-forge='premiere'][data-forge-tier='L3'] .forge-premiere__arc` |

> **`prog` 在装台区的取法（FX-3/FX-4 的关键决定）**：`AssembleProps`（`ui.ts`，flow-state 拥有）
> 不含 `prog`，本轮不动 `ui.ts`，所以 `Assemble.tsx` 用 `deriveProg(props.stage, props.done, props.total)`
> **复算** reducer 的同一条公式（`cast → 2`、`STAGE_PROG[stage]`、`max(·, 2 + 3·done/total)`）。
> 三个输入就是 reducer 算 `prog` 的三个输入，因此值恒等于 `state.prog`；它是**读数**，不是第二个进度源：
> 没有 `slide:landed` 就没有 `done` 自增，也就没有任何爬升。
> 唯一不等的地方是 `deck` 分支的 `prog=6.4`——那一刻 `phase='premiere'`、`Assemble` 已经卸载，速度不再被读。

## 4. FX-1 落位冲击波 `ring`

**语义**：`slide:landed` 那一帧，从幕心向外推一枚 1px 环，520ms 缩放到 1.34 倍并淡出到 0。
它**不替代** v0.2.0 的 `.forge-stage__ping`（320ms 贴面闷响环，`04` §2.4 的第一列），两者分工：

| 装置 | 时长 / 缓动 | 读法 | 数据源 |
|---|---|---|---|
| `.forge-stage__ping`（v0.2.0 基线，未改） | 320ms / `--fx-ease-settle`，`scale(.62)→1.62`、`opacity .42→0` | 「贴面回弹」 | `done` |
| `.forge-stage__shock`（本轮新增） | 520ms / `--fx-ease-settle`，`scale(.72)→1.34`、`opacity .58→0` | 「向外扩散的冲击」 | `done` + `active` |

| 关键帧 | 0% | 38% | 100% |
|---|---|---|---|
| `.forge-stage__shock`（主环） | `scale(.72)` `opacity .58` | `opacity .34` | `scale(1.34)` `opacity 0` |
| `.forge-stage__shock::before`（外环，L3/L2） | `scale(.86)` `opacity 0` | `opacity .42`（24%） | `scale(1.14)` `opacity 0` |

| 档 | 形态 | 实现 |
|---|---|---|
| L3 | 520ms 缩放 + 外环 + `blur(.6px)` + 柔光 | 基类规则 + `.forge[data-forge-tier='L3'] .forge-stage__shock` |
| L2 | 同 L3 但**无模糊/无柔光** | `.forge[data-forge-tier='L2'] .forge-stage__shock { filter:none; box-shadow:none }` |
| L1 | **120ms 只淡出**（`forge-shock-fade`），无缩放、无外环 | `.forge[data-forge-tier='L1'] .forge-stage__shock` |
| L0 / `?still=1` | **无**（`display: none`） | `.forge[data-forge-tier='L0'] .forge-stage__shock`、`.forge[data-forge-still='1'] …` |

**为什么不会假播**：`key={shock-${done}-${active}}`。`done` 只在 `slide:landed` 自增，
`active` 也在同一分支被写成 `event.index`；React 只有在 key 变化时才重挂载元素，
而 key 的两个成分都只由这一个事件改写。重铸成功走 `slide:recast` → `recastDone`，`active` 不变但
`done` 也不变，因此**重铸不重播冲击波**（重铸的重播由 `.forge-stage__center` 的 `key={activeSlide.id}` 承担），
这与「冲击波 = 一次新幕落位」的读法一致。

**可测钩子**：`[data-forge-shock]`（值 = `done`）。

## 5. FX-2 完成栈深度

**语义**：左侧完成栈每多一层，纵深加 18px、亮度降一档——`done` 变化即重排。

| 量 | 公式 | depth=0…4 的实值 |
|---|---|---|
| `translateZ`（仅 L3） | `-depth × --fx-depth-z` | `0 / -18 / -36 / -54 / -72px` |
| `brightness`（行内，源自 v0.2.0） | `1 - 0.12·depth` | `1 / .88 / .76 / .64 / .52` |
| `opacity`（行内，源自 v0.2.0） | `max(.3, 1 - 0.13·depth)` | `1 / .87 / .74 / .61 / .48` |
| 过渡 | `filter/opacity/transform 320ms`（`--fx-t3`） | L3 三条、L2 两条（无 transform） |

| 档 | 纵深 | 逐层降亮 |
|---|---|---|
| L3 | `translateZ(-i·18px)` | 有（带 320ms 过渡，所以"递进"看得见） |
| L2 | 无（压平） | 有（带过渡）——**只降亮** |
| L1 | 无 | 静态终态（v0.2.0 的行内亮度照旧，没有过渡：`?still=1`/L1 不做"递进"动画） |
| L0 / `?still=1` | 无 | 静态终态（整层 `transition: none !important`） |

**证据**：`--forge-depth` 写在 `Assemble.tsx` 的每层 thumb 上行内（`depth` 来自 `stack.map` 的序号，
`stack` 来自 `landedOf(slides)`，而 `status='landed'` 只由 `slide:landed` 写入）；
栈容器的 `data-forge-depth={done}` 是"已落位总数"的读数、`data-forge-stack={stack.length}` 是"左侧实际
叠了几张"，两者一起供 e2e 直接断言（`done` 含中心幕，所以通常比 `stack.length` 多 1）。

**可测钩子**：`.forge-assemble__stack[data-forge-depth]`、`.forge-assemble__thumb[data-stack-depth]`、
行内 `--forge-depth`。

## 6. FX-3 Pulse 环形进度

**语义**：`prog`（0–7 连续量）直接换算成 SVG 环的 `stroke-dashoffset`，柱阵（v0.2.0）继续保留——
环是"整体进度"，柱是"七段读数"，两者同源同值。

```ts
// hud/Pulse.tsx —— props 契约不变（prog / stage / bad / tier / label）
export const PULSE_RING_R = 8            // viewBox 24×24，圆心 (12,12)
export const PULSE_RING_CIRC = 2πR       // = 50.265
export const PULSE_PROG_MAX = 7
pulseRingProgress(prog) = clamp(prog / 7, 0, 1)   // NaN → 0
pulseRingOffset(prog, C = PULSE_RING_CIRC) = C × (1 - progress)
```

| `prog` | 0 | 2（cast） | 3.5 | 5（首幕落定后的 check 基线） | 6.4（seal） | 7 |
|---|---|---|---|---|---|---|
| `progress` | 0 | .286 | .5 | .714 | .914 | 1 |
| `stroke-dashoffset` | 50.265 | 35.9 | 25.13 | 14.36 | 4.31 | 0 |

| 关键帧 | 值 |
|---|---|
| `stroke-dasharray` | 周长（定值 50.265，属性写出，避免 CSS 与 JS 两处真值） |
| `stroke-dashoffset` | `pulseRingOffset(prog)`（属性写出） |
| 过渡 | `stroke-dashoffset 320ms var(--fx-ease)`（与柱高同一条曲线，`04` §4.3「同一件事只允许一条时间曲线」） |
| 环的朝向 | `svg { transform: rotate(-90deg) }`，从 12 点方向起画 |
| `bad` | `stroke: var(--ui-danger)`（环）/ `background: var(--ui-danger)`（线性条） |
| 充能 | `stroke-linecap: round`，`stroke-width: 2` |

| 档 | 形态 | 实现 |
|---|---|---|
| L3 | 环 | `.forge[data-forge-tier='L3'] .forge-pulse__ring { display: grid }` |
| L2 | 环（同 L3，`04` §10.1 的 Pulse 无模糊差异） | 同上 |
| L1 | **线性条**（44×2px，`scaleX(progress)`） | `.forge[data-forge-tier='L1'] .forge-pulse__linear` |
| L0 / `?still=1` | **静态条**（同一个 `progress`，`transition: none`） | `.forge[data-forge-tier='L0'] .forge-pulse__linear`、`[data-forge-still='1'] …` |

**证据**：`prog` 由 `state.ts` 四处写：`submit(0.4)`、`outline(1.6)`、`cast(2)`、`stage → STAGE_PROG[stage]`、
`slide:landed → max(prog, 2 + 3·done/total)`、`deck(6.4)`。`Pulse` 只做 `clamp(prog - i, 0, 1)` 与
`pulseRingProgress(prog)` 两次读数，自身不持有任何状态、不写 rAF。

**可测钩子**：`[data-forge-pulse]`、`[data-forge-pulse-ring]`、`[data-forge-pulse-linear]`、
`[data-forge-prog]`（= 本次渲染的 `prog`，e2e 可读）。

## 7. FX-4 环境粒子随进度加速

**语义**：粒子的旋转速度是 `prog` 的函数（×1.0 → ×2.2），每次落位打一次 rip；L2 及以下**根本没有粒子**
（`startAmbient` 对 `tier !== 'L3'` 直接返回 NOOP，连 canvas 都不建）。

```ts
// fx/ambient.ts —— 两个纯函数 + 两个句柄方法
ambientSpeed(prog) = 1 + 1.2 × clamp(prog, 0, 7) / 7      // prog 0→7 ⇒ ×1.000→×2.200
AMBIENT_RIP_GAIN   = 1.6                                   // rip 峰值 = speed × 2.6
AMBIENT_RIP_MS     = 420                                   // 能量线性衰减回 0
handle.setProgress(prog)  // 只改闭包里的标量，不重建 WebGL、不重启任何动画
handle.rip()              // 只把 ripEnergy 置 1，衰减发生在既有 rAF 的 delta 上
```

| `prog` | 0 | 2（cast） | 3（首幕落定） | 5 | 6.4（seal） | 7 |
|---|---|---|---|---|---|---|
| `speed` | 1.000 | 1.343 | 1.514 | 1.857 | 2.097 | 2.200 |
| 落位瞬间（rip = 1） | 2.6 × speed | — | — | — | — | — |

| 帧 | 位移/透明度 |
|---|---|
| 每帧 | `points.rotation.z += step × 0.012 × speed × (1 + 1.6·rip)`；`rotation.y = sin(now · 4e-5 · rate) · .06` |
| rip 衰减 | `ripEnergy -= min(delta, 64) / 420`（同一个 rAF 的 delta，无计时器） |
| 光晕 | `halo.opacity = .05 + sin(now · 3.5e-4 · rate) · .015 + .05 · ripEnergy` |

| 档 | 粒子 |
|---|---|
| L3 | 96 点（暖金 65% + 冷青 35%），`pixelRatioCap 1.5`，`opacity .55` |
| L2 / L1 / L0 / `?still=1` | **关闭**（`startAmbient` 返回 NOOP；`prefers-reduced-motion`、`saveData`、设置里的 `ambient=false` 同样关） |

**资源释放不变**：`Assemble` 的 `useEffect(..., [tier])` 在卸载/换档时 `handle.dispose()`——
释放 rAF 订阅、geometry/material/renderer、`forceContextLoss()` 并移除 canvas；
`dispose()` 幂等（单测里连续调两次不抛，且 `ambientCanvasCount(host) === 0`）。
`setProgress`/`rip` 在 `disposed` 之后是 no-op，不会往已卸载的树里写。

**可测钩子**：`[data-forge-ambient-host]`（宿主，`canvas[data-forge-ambient="1"]` 恰好 0 或 1 个）。

## 9. FX-6 过检火花密度分级

**语义**：`error` 时从幕心向外的短线束数按档位分级——只改「几束」，不改「有没有 error」。

| 档 | 束数 | 形态 |
|---|---|---|
| L3 | **12** | 椭圆轨道 470×300，`θ = 360°/12·i + 13.8°`，长 12/18/24px 三档，金色渐变 |
| L2 | **6** | 同轨道几何（步进 60°），金色渐变 |
| L1 | **3** | 同轨道（步进 120°），**无渐变**（纯 `--ui-accent`） |
| L0 / `?still=1` | **0** | 只有方形「!」角标（`data-severity="error"` 仍在） |

| 关键帧 | 0% | 24% | 100% |
|---|---|---|---|
| `.forge-gate__burst` | `scale(.94)` `opacity 0` | `opacity 1` | `scale(1.02)` `opacity .28`（320ms） |

**不变量**：`data-severity="error"`（1 处）与 `data-severity="warn"`（1 处）的**数量不变**——
档位只削减视觉束数，读屏通道（`role="alert"`）与 e2e 的严重度判据完全不受档位影响。
`raysOf(count)` 的首个角度仍是 `+13.8°`，所以 12 束不会读成"12 个箭头"。

**可测钩子**：`[data-forge-burst]`、`[data-forge-sparks]`（= 实际束数）。

## 10. FX-7 完成收束

**语义**：`deck:done` 之后把弧线"合拢"到位——这是开演前最后一跳，之后才轮到 `premiere` 屏自己的按钮。

| 关键帧 | 0% | 55% | 100% |
|---|---|---|---|
| `.forge-premiere__arc / __grid`（L3） | `opacity .42` `scale: 1.03` | `opacity .92` | `opacity 1` `scale: 1` |
| 时长 / 缓动 | `620ms`（`--fx-close`）/ `var(--fx-ease-settle)` | | |

用**独立的 `scale` 属性**而不是 `transform`，这样 `T3-a` 的容器 `transform: scale(.84)` 与 `T3-b` 的
`rotateX(10deg)` 都不被覆盖，卡片自己的行内 `translate3d/rotateY`（每个 `index` 一份真值）也不被动画吃掉。

| 档 | 形态 |
|---|---|
| L3 | 弧线合拢 620ms（`forge-arc-close`：`scale 1.03→1` + `opacity .42→1`） |
| L2 | **淡出 320ms**（`forge-premiere-fade`，只收不透明度，不缩放） |
| L1 | 320ms 淡入（同上一条 keyframes；无缩放） |
| L0 / `?still=1` | 无（整层 `animation: none !important`） |

> **与 `02` §6.1 的字面差异（已对齐）**：§6.1 表的 L1 列写「无」，本轮按任务口径给 L1 保留
> **320ms 的不透明度收束**（"无"指没有合拢运动）。理由与 `04` §10.2 同一条：降的是运动幅度，
> 不降"发生了什么"；L2/L1 共用一条 keyframes，因此只有 1 处 `forge-premiere-fade` 定义。

**证据**：`deck:done` → `dispatch({type:'deck'})` → `phase='premiere'` → `forgeMark()==='premiere'`
→ 根节点 `data-forge='premiere'`。CSS 的触发条件就是这一个属性，没有任何 `animation-delay` 或 JS 定时器。

## 12. 与 v0.2.0 的差异（只做增量，不推翻基线）

| # | v0.2.0 | v0.2.5 | 性质 |
|---|---|---|---|
| 1 | 落位只有 320ms 闷响环（`forge-ping`） | **新增** 520ms 冲击波 + L3 外环；闷响环一字未改 | 增量 |
| 2 | 完成栈亮度/不透明度是行内静态值，无夜间读法 | 亮度不变，**新增** `--forge-depth` 与 L3 纵深、320ms 过渡 | 增量 |
| 3 | Pulse 只有 7 根柱 | **新增** SVG 环 + `pulseRingOffset()`；柱阵一字未改 | 增量 |
| 4 | 粒子只有恒定角速度 | 速度改由 `prog` 驱动 + 落位 rip；粒子数/颜色/宿主规则不变 | 改写（同一装置，新增读入） |
| 5 | 开演席卡片只有 `forge-arc-in`（`--i` 未赋值，错峰形同虚设） | `--i` 由 `nth-child` 赋真值 + 新增 `::after` 扫光（40ms） | 增量 + 一处"活化" |
| 6 | Gate 火花固定 8 束 / L1 4 束 / L0 0 束 | 改为 12 / 6 / 3 / 0 | 改写（分级） |
| 7 | 开演席进入没有收束动画 | 新增 620ms 弧线合拢 / 320ms 不透明度收束 | 增量 |

**唯一"顺手活化"的地方**（第 5 条，必须显式记账）：`forge.css` 里 `.forge-premiere__card` 的
`animation-delay: calc(var(--i, 0) * 26ms)` 在 v0.2.0 是死代码（没人写 `--i`）；本轮为了让 FX-5 的
40ms 错峰只靠纯 CSS 成立，给 `:nth-child(1..20)` 赋了 `--i`，因此这条 26ms 错峰**从这一轮开始生效**。
它不改时长、不改曲线、不改 DOM，只是让原本写好的表达式真的算出值；若要回退，只需删掉 20 行
`nth-child` 规则并给 FX-5 换一个专用变量名。

**没有推翻的基线**：`--fx-*` 阶梯值、六段动效脚本、块入场 `enter/enterDelayMs` 的 `!important` 补写、
Gate 的 320ms 闭环、`04` §10.2 的"降形态不降信息"、音频与档位解耦。
