# 02 · v0.2.5 工作流编排与契约

> **本文件是 v0.2.5 的唯一契约源**。`00` 定边界，`01` 定排期，本文件定**接口**：
> 谁改哪个文件、类型长什么样、DOM 钩子叫什么、文案叫什么词、动效挂在哪个状态上。
> 实现与测试都按这里的签名走；要改签名先改这里，再改代码。

参照对象：[THU-MAIC/OpenMAIC](https://github.com/THU-MAIC/OpenMAIC) 的用户逻辑（不是它的代码）。
取它的**四条使用逻辑**，不取它的技术栈（它是 Next.js + PostgreSQL 多智能体课堂，LUMEN 是纯前端本地工作台）：

| 借鉴的机制 | OpenMAIC 的做法 | LUMEN v0.2.5 的落法 | 为什么不照搬 |
|---|---|---|---|
| **材料先于提示词** | 上传 PDF/Word/PPT/表格/文本/音视频 → 抽取器 → 生成时引用 | 起念屏「材料篮」：粘贴 / 网址 / 本地文本文件（`.txt/.md/.json`），≤5 条、每条 ≤4000 字，拼进 `outlineRequest` 与 `slideRequest` | 没有服务端，不做二进制解析（PDF/PPT 需 WASM 解析器，v0.2.5 半周期放不下） |
| **大纲是闸门，不是结果** | 两步管线：Outline → Scenes，大纲可编辑后再生场景 | 大纲卡阵支持**逐幕改写标题**与**写这一幕想讲什么（brief）**，并可在此换设计预设 | 我们已经有 12 配方卡阵，缺的是"进生成之前能改内容" |
| **生成中可纠偏（steering）** | 会话运行中可追加指令，在下一个场景边界生效 | `SteerBar`：生成中写一句「后面几幕要更短」，队列在**下一幕边界**注入该幕 `brief`，显示"第 n 幕起生效" | 我们是一请求一幕的池化管线，事件边界天然存在，不需要 DB lease |
| **完成后不跳出工作流** | 课堂面板 tabs 常驻；建议下一步 | 开演席三枚下一步：播放 / 继续编辑 / 再加几幕；latte 级「最近一套」可恢复 | 我们不开多文档工作台（v0.3 议题），只做单套闭环的续接 |

## 1. 本轮新增的五个用户动作

| # | 动作 | 从哪进 | 改了什么状态 | 落哪个文件 |
|---|---|---|---|---|

## 2. 类型契约（`src/forge/types.ts`，flow-state 拥有）

```ts
/** 材料：只有文本进入模型，二进制一律不解析（00 §6 边界）。 */
export type MaterialKind = 'paste' | 'url' | 'file'
export type MaterialStatus = 'ready' | 'parsing' | 'failed'

export interface ForgeMaterial {
  id: string            // mat-<ts>-<rand4>
  kind: MaterialKind
  label: string         // 用户内容，展示截 24 字符（D 类预算）
  text: string          // 正文，硬上限 MATERIAL_TEXT_MAX = 4000
  tokens: number        // 估算，见 materials.ts 的 estimateTokens
  at: number
  status: MaterialStatus
}

/** 生成中追加的一条要求；fromIndex 是它开始生效的幕序号。 */
export interface SteerNote {
  id: string            // st-<ts>-<rand4>
  text: string          // ≤60 字，硬截
  fromIndex: number
  at: number
}

/** 「最近一套」：只存大纲级别，不存成品 Deck（体量）。 */
export interface ReuseEntry {
  id: string
  title: string
  prompt: string
  themeId: string
  count: number
  at: number
  outline: Outline
}
```

`ForgeState` 追加五个字段（其余一字不改）：

```ts
materials: ForgeMaterial[]
audience: string          // '' | 'exec' | 'team' | 'client' | 'class'
themeId: string           // 默认取当前 deck.themeId
steer: SteerNote[]
reuse: ReuseEntry[]       // 由 ForgeApp 异步灌入，初始 []
```

`ForgeAction` 追加：

```ts
| { type: 'material:add'; material: ForgeMaterial }
| { type: 'material:patch'; id: string; patch: Partial<Pick<ForgeMaterial, 'status' | 'text' | 'tokens'>> }
| { type: 'material:remove'; id: string }
| { type: 'audience'; value: string }
| { type: 'theme'; themeId: string }
| { type: 'headline'; index: number; value: string }
| { type: 'brief'; index: number; value: string }
| { type: 'steer'; note: SteerNote }
| { type: 'steer:remove'; id: string }      // 撤销：从 steer[] 摘掉，并把当初追加进未落位幕 brief 的那段精确摘除
| { type: 'reuse'; entries: ReuseEntry[] }
```

> `steer:remove` 是 §2 初稿漏写的：SteerBar 的「撤销」必须有对应动作，且**不能只删队列**——
> 已经写进未落位幕 `brief` 的那半句要原位摘掉（首/中/尾三种位置都要处理），否则用户点了撤销、下一幕还是按旧要求生成。
> 已落位幕一律不动；id 不存在时原样返回 state。

**Reducer 硬约束**（`tests/unit/forge-state.test.ts` 的 37 条一条不许红）：

1. `reset` 保留 `lang/length/durationMin/includeSvg/include3d/autoPremiere/themeId/audience/materials`，清空 `steer/prompt/outline`。
2. `theme` 只在 `seed`/`deal` 有效；`casting`/`premiere` 期间返回原 state（不换主题重排已生成幕）。
3. `headline`：`trim()` 后为空则忽略；截 120。`brief`：截 200。
4. `steer`：`note.fromIndex` 必须 ≥0 且 < `slides.length`，否则忽略；写入后对 `i >= fromIndex` 且未落位的幕，把 `note.text` 以 `；` 追加进该幕 `brief`（再截 200），已落位幕不动。
5. 材料上限 `MATERIAL_MAX = 5`：第 6 条 `material:add` 返回原 state。
6. `option`/`prompt`/`swap`/`move`/`remove`/`add`/`cast`/`stageEvent`/`deck`/`stop`/`recast*` 行为零变化。

### 6.1 生成过程动效（fx-artist，`03-视觉动效.md`）

### 6.2 设计预设（themes，`04-设计预设.md`）

`themeSchema` 追加三个**可选**字段（旧 Deck 反序列化不受影响）：

```ts
texture: z.object({ kind: z.enum(['none','grain','grid','scan','dots']), opacity: z.number().min(0).max(1) }).optional(),
glow: z.number().min(0).max(1).optional(),        // accent 光晕强度
elevation: z.enum(['flat','raised','layered']).optional(),
```

`themeCssVars` 追加变量（导出与渲染共用同一条路）：

```ts
'--d-texture': kind, '--d-texture-op': opacity,
'--d-glow': glow, '--d-elevation': elevation,

'--d-accent-soft': accent 的 12% 透明混合
```

六套预设逐套打磨，验收口径：正文对比度 ≥ 7:1、muted ≥ 4.5:1、accent 在 bg 上 ≥ 3:1（`src/lint/color.ts` 已有对比度函数，测试直接复用）。

### 7.1 已记录的实现局限（v0.2.6 议题，不在本轮修）

| # | 局限 | 影响 | 为什么不在这轮修 |
|---|---|---|---|
| L-1 | `move` / `remove` 只重排卡片，不搬动 `outline.slides[i].brief`，要点留在原幕序号上 | 用户在**先写要点、后拖动换序**时会错位 | 修它要么给 `ForgeSlideState` 加 `brief` 字段（改状态契约），要么让 `move` 同时重排 outline（改既有分支行为，`forge-state.test.ts` 会红）。两者都超出"半周期只做加法"的边界 |
