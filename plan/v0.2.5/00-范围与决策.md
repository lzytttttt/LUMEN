# 00 · v0.2.5 范围与决策

> **一句话定位**：v0.2.0 把「右栏表单」换成了造幕台，v0.2.5 是**版本中期迭代**——
> 不改内核契约，只做两件事：**把生成前后的用户动作串成一条顺的路**（参照 OpenMAIC 的使用逻辑）、
> **把生成过程中的动效与 6 套设计预设再磨一遍**。
>
> 版本语义：`0.2.5` 是 `0.2.x` 内部的**加法迭代**。Deck / Outline / 导出的对外契约只做**可选字段加法**，
> 任何 v0.2.0 存下的 Deck、草稿、`?channel=replay` 回放数据必须原样可读。破坏性变更留给 `0.3.0`。

---

## 1. 交付什么（四条）

| # | 交付 | 一句话验收 | 落点 |
|---|---|---|---|
| 1 | **工作流编排** | 用户能「先给材料 → 看到大纲并改内容 → 生成中纠偏 → 开演后继续」，四段之间不用退出造幕台 | `src/forge/**`、`src/ai/{compose,prompts}.ts` |
| 2 | **生成过程视效** | 落位冲击波、完成栈深度、环形进度、粒子随进度加速、火花分级七条效果，四档降级可复现 | `src/forge/forge.css`、`fx/`、`stage/{Assemble,Gate}.tsx`、`hud/Pulse.tsx` |
| 3 | **设计预设打磨** | 6 套预设的对比度/层次/纹理/光晕达标，编辑器所见 = 导出所得 | `src/themes/index.ts`、`render/slide.css`、`export/` |
| 4 | **计划与验收文档** | `plan/v0.2.5/00–05` 六篇 + `03`/`04` 两份实现规格，可核对 | `plan/v0.2.5/` |

## 2. 不交付什么（避免误读）

| 不做 | 为什么 |
|---|---|
| PDF / Word / PPT 二进制解析 | 需 WASM 解析器与体积预算，半周期放不下；材料只收**文本**（粘贴 / 网址 / `.txt .md .json .csv`） |
| 服务端会话、断点续跑的云端任务 | LUMEN 是纯前端本地工作台，没有后端；"可恢复"用 IndexedDB 的 `forge/draft` 与 `forge/reuse` 做，不做 lease |
| 多文档工作台 / 文件夹 / tabs | 那是 v0.3.0 的议题；本轮只做**单套闭环的续接** |
| 新的 12 配方 / 新主题 | 配方与主题是**稳定资产**，本轮只打磨既有 6 套，不新增 7 号 |
| 播放器、导出、lint 阈值的规则变更 | 保持 v0.2.0 行为，避免把验收基线一起推翻 |
| 游戏化扩展 | v0.2.0 已定"零阻塞"，本轮只保留既有连击/成就，不加新机制 |

| 界面词 | 内部代号 | 含义 |

## 4. 锁定的 10 条决策

| # | 决策 | 理由 | 落到哪 |
|---|---|---|---|
| **D-25-1** | 半周期只做两条主线（流程 + 视觉），不加新存储/新后端 | 中期迭代的价值在"把已有的路走顺"，不在摊新饼 | 本文件 §1 §2 |
| **D-25-2** | 材料只收文本，≤5 条、每条 ≤4000 字 | 二进制解析是体积与工期双重黑洞；4000 字已够"一段背景资料" | [02](02-工作流编排与契约.md) §3.1 |
| **D-25-3** | 大纲是闸门：`headline` + `brief` 是**唯一**用户→生成侧指令通道 | 一个通道好验证、好回放；不引入"自由聊天"式不可控输入 | [02](02-工作流编排与契约.md) §3.4 |
| **D-25-4** | 纠偏在**幕边界**生效，不取消在跑的请求 | 池化管线天然有边界；取消重跑会让已付的 token 白花 | [02](02-工作流编排与契约.md) §2 约束 4 |
| **D-25-5** | 设计预设**不新增**，只打磨 6 套；新能力用**可选** token 表达（texture/glow/elevation） | 加法 token 旧 Deck 仍可读；新增主题会稀释"少而准"的取向 | [02](02-工作流编排与契约.md) §6.2 |
| **D-25-6** | 文字预算不放开：材料/受众/预设/纠偏入口一律 **ghost 级**，不计 `data-forge-text` | v0.2.0 的"少字"是产品取向，不是实现细节；新增入口不该换来满屏标签 | `04` 与 `tests/unit/forge-copy.test.ts` |
| **D-25-7** | 动效只由 `ForgeStageEvent` 与 `prog` 驱动，禁止假进度 | 用户看到的节奏必须等于真实产出节奏；这是 v0.2.0 的 D2，本轮不放宽 | [02](02-工作流编排与契约.md) §6.1 |
| **D-25-8** | 四档回落（L3/L2/L1/L0 + `?still=1`）是本轮所有新动效的**交付物之一** | 低端机与截图基线不能因"更好看"而退化 | [02](02-工作流编排与契约.md) §6.1 表 |
| **D-25-9** | 对外契约只做可选字段加法（`outline.brief`、`theme.texture/glow/elevation`） | 半周期不改 schemaVersion，`migrate.ts` 零改动 | [02](02-工作流编排与契约.md) §3.4 §6.2 |
| **D-25-10** | 仍然无后端、无遥测、无上传；数据只在本机 IndexedDB | 与 v0.2.0 的隐私承诺一致 | `src/persistence/**` 零改动 |

## 5. 界面词规则（沿用并收紧）

1. **界面说人话，代号留给代码**（v0.2.0 D13 不变）：屏幕上只有「材料 / 受众 / 预设 / 要点 / 纠偏 / 继续编辑 / 再加几幕」，`material` / `steer` / `brief` / `reuse` 这些词只出现在 i18n key、`data-*` 与代码里。
2. **一枚按钮一个动词，最长 4 字**；主按钮仍是 `生成大纲` / `开始生成`——本轮**不新增主按钮**。
3. **字数预算四级**（A 4 字 / B 3 字 / C 6 字 / D 14 字）不变；新材料文案逐条列在 [02](02-工作流编排与契约.md) §5，不许自创。
4. **禁用词照旧**：不许「智能/一键生成/即将上线/为你/稍等/完美/抱歉/幻灯片/PPT」等（完整表在 `plan/v0.2.0/09-文案词表.md` §5，`tests/unit/forge-copy.test.ts` 机械校验）。
5. **不写数字进度**：开演席仍不出现百分比；纠偏条上的「第 n 幕起」是**唯一**允许的序号文案。

## 6. 视觉基调（复审按这个判）

**深色、单一束光、几乎不写字、每次落位都有"咔哒"感**。不是霓虹赛博，不是仪表盘，不是渐变堆叠。

本轮允许的增量：冲击波环、深度分层、环形进度、粒子加速、卡片扫光、火花分级、收束合拢。
**不允许**：粒子雨、彩色光斑糊满屏、超过 900ms 的入场、任何遮挡幕卡内容的浮层装饰。

## 7. 降级与无障碍（不放宽）

| 档位 | 判定 | 新动效的表现 |
|---|---|---|
| L3 | WebGL2 且 ≥4 核 | 全量（粒子 + 深透视 + 环形进度） |
| L2 | 无 WebGL2 或核数不足 | 有环/有冲击波，无粒子、无 Z 透视 |
| L1 | `prefers-reduced-motion`、≤2 核、`saveData` | 只保留 ≤320ms 的淡入淡出 |
| L0 | `?still=1` 或设置里锁档 | 一切新动画 `animation: none`，静态可读 |

无障碍三条硬约束：`aria-live` 仍只有一处且节流 ≥1.5s；纠偏条与材料篮全部可 `Tab` 到达、`Enter` 提交、`Esc` 取消；错误只用「短句 + 一个动词按钮」。

## 8. 风险登记（本轮）

| # | 风险 | 触发条件 | 处置 |
|---|---|---|---|
| R1 | 新入口把文字预算顶破，`forge-copy.test.ts` 大面积红 | 材料/纠偏/预设被做成带标题的区块 | 全部走 ghost 级；唯一放行是 `cast.steerQueued` 进 F 类 |
| R2 | `liveOutline` 让已生成幕与大纲不一致 | 纠偏写入已落位的幕 | reducer 约束 4：只改未落位幕；已落位幕由「重试」单独处理 |
| R3 | 纹理/光晕拖慢渲染 | 每块都叠 `filter: blur` | 纹理只在幻灯片根层一层；光晕用 `box-shadow` 不用 `filter` |
| R4 | 四路线并行改坏同一文件 | 有人越界写别人的文件 | [02](02-工作流编排与契约.md) §7 文件归属表；冲突即违约，回退重做 |
| R5 | 材料把 prompt 顶爆上下文 | 5 条 × 4000 字直接拼入 | prompt 里每条只取前 200 字摘要，硬编码上限，不随用户长度膨胀 |

## 9. 与 v0.2.0 的关系（一张表看清改了谁）

| 面 | v0.2.0 | v0.2.5 |
|---|---|---|
| 起念屏 | 一句话 + 三组刻度 + 示例卡（5 块文字） | 加 ghost 级「材料 / 受众 / 预设 / 最近」，**文字块数量不变** |
| 大纲屏 | 6×卡阵 + 换卡环 + 增删排序 | 加**卡内改标题**与**要点编辑**、页头预设切换 |
| 生成屏 | 完成栈 + 当前幕生长 + Pulse + Gate | 加**纠偏条**；落位冲击波、栈深度、环形进度、粒子加速、火花分级 |
| 开演屏 | 弧线/网格 + 播放 | 加**继续编辑 / 再加几幕**两枚 ghost + 扫光与收束 |
| 预设 | 6 套色板 + 字号刻度 | 6 套打磨 + `texture/glow/elevation` + `surface-2/accent-soft/shadow` 变量 |
| 契约 | `Outline`/`Deck`/`Theme` | **只加** `outline.brief?`、`theme.texture?/glow?/elevation?` |
